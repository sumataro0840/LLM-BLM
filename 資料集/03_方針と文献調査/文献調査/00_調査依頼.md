# 依頼：LLM-BLM の実験結果を踏まえた先行研究の調査

この文書は、Claude・GPT・Gemini（Deep Research を含む）に**同じ内容で**渡す依頼である（2026-10-17）。各者は独立に調べて書き、後で比較する。

## 背景

- 大学の授業の 1 人の研究で、S&P500 の銘柄について、LLM の予想を Black–Litterman モデル（BLM）のビューに入れて追加の価値があるかを検証した。
- 結果の要約は添付の `00_依頼.md`（前提・データ・主な結果）にある。次の方針の 3 案の比較は `比較検討.md` にある。
- 要点は次のとおり。
  - gpt-4o-mini に銘柄ごとの翌月リターンを数値で答えさせた。その予想は、渡した月の値動きの写しだった（決定係数 0.81）。写しを除いた固有の予測力は IC 0.03 未満。
  - 回答のばらつきを Ω に使う案は、ばらつきが誤差の大きさと順位で合わず、棄却した。過去の当たり具合で Ω を較正すると、BLM は設計どおりに動いた。ただし成績は、予想を並べ替えたビューと区別できなかった。
    - **【訂正（2026-10-17、送った後に Claude が気づいた）】**上の 1 文目は誤りである。正しくは「ばらつきは誤差の大きさとしては確信が強すぎて使えない（外れの 2 乗の約 8 分の 1）。一方で、外れやすさの順番の手がかりにはなった（偏順位相関 +0.17）」。GPT は添付の実験結果レポートから正しく読んだ。Gemini と Deep Research には、誤った文のまま渡っている。
  - 相対ビューにしても、高ベータへの傾きは消えなかった。
  - 決算発表文（8-K の EX-99.1、5,429 本）から LLM で取り出した点数は IC +0.033（探索的）。数値の情報を統制すると有意でなかった。
  - 成績をフィードバックすると、LLM は一律に強気に寄った。
  - 評価は 30 か月だけで、検出力が足りない。
- 次の方針では、3 者が次の点で一致した。
  - LLM は決算発表文から点数を取り出す役に絞る。
  - 決算発表のイベントの単位で評価する。
  - LLM を使わない文章の分析（辞書、TF-IDF、FinBERT）と比べる。
  - BLM は、検証を通った信号を比率に変える部分として使う。
- 意見が分かれたのは次の点。
  - 知識の期限（2023-10）より前の文章を匿名化して使ってよいか。
  - 前向きの検証を主な検定にするか。
  - 意味のある最小の効果の大きさ。
  - BLM を単純な順位の戦略と比べて外す可能性。

## 調べてほしいこと

次の 8 つのテーマについて、**実際に存在を確かめた**論文・ワーキングペーパーを挙げる。2023〜2026 年の LLM と金融の研究を重視する。古典も、設計の根拠になるものは含める。

1. **LLM の数値の予想と外挿**
   - LLM の株価・リターン・マクロの予想は、直近の値の外挿や入力の数字への引きずられ（アンカー）を示すか。
   - 数値の情報を統制した後に、LLM に固有の予測力は残るか。
2. **先読み（look-ahead）と記憶の問題、その対策**
   - 匿名化（社名・日付・数字を伏せる）の効果と限界。
   - 知識の期限の前と後での比較。
   - 時点ごとに学習を区切ったモデル（point-in-time、chronologically consistent な LLM）の有無と性能。
   - 記憶の混入を検定する方法。
   - **これが「2023 年以前の文章を使ってよいか」の判断の根拠になる。**
3. **決算発表文・決算説明会の文章と株価**
   - 発表後の超過リターン、PEAD、文章による驚き。
   - LLM・FinBERT・辞書（Loughran–McDonald など）・TF-IDF や機械学習の比較。
   - 報告されている効果の大きさ（IC、ロング・ショートのリターン、CAR）。
   - 数値の驚き（SUE）を統制した後に、文章の情報が残るか。
4. **イベントスタディの設計**
   - EDGAR の受理時刻と公開時刻、引け後・場中の発表の扱い。
   - 同じ日の発表どうしの相関（クラスタリング）。
   - 検出力と、必要な標本の大きさ。
5. **LLM の不確実性の表現**
   - 複数回の回答のばらつき、言葉で述べた自信、確率（logprob）が、誤差の大きさと対応するか。
   - 金融の予想での報告。
6. **BLM とビューの設計**
   - 定量・機械学習・LLM のビューを入れた BLM の実証研究（2024〜2026 の LLM×BLM を含む）。
   - Ω の較正（過去の予想誤差、Idzorek など）。
   - 相対ビューとベータの中立化。
   - BLM が単純な順位のポートフォリオや平均分散に勝つかの証拠。
7. **評価の確かさ**
   - バックテストの過剰適合（deflated Sharpe など）、多重検定。
   - 置換（プラセボ）の対照。
   - 事前登録・前向きの検証を金融の機械学習に使った例。
   - LLM の金融のベンチマークの汚染。
8. **フィードバックと LLM の偏り**
   - 成績の情報を与えると強気や同調に寄るか（sycophancy、楽観の偏り）。
   - LLM のエージェントによる取引の研究での報告。

## 書き方

日本語の Markdown で、次の見出しをこの順に使う。分量の目安は 8,000〜15,000 字。

1. **要旨**：調査から分かったことのうち、次の方針を左右するもの（5〜10 個）
2. **テーマ別の調査結果**（上の 1〜8 の順）。各テーマは次の 3 つで書く。
   - **主要な文献の表**：著者、年、題名、掲載先（査読済み／ワーキングペーパー／プレプリント）、識別子（DOI・arXiv の番号・SSRN の番号・URL のどれか）、要点（1〜2 文、数値があれば添える）
   - **今回の実験との対応**：その文献と、今回の結果が一致するか、矛盾するか
   - **方針への含意**
3. **意見が分かれた論点への文献からの判断**。各論点は「文献はどちらを支持するか、どの程度確かか」で書く。
   - 期限より前の文章の匿名化での使用
   - 前向きの検証
   - 意味のある最小の効果
   - LLM を使わない対照の選び方
   - BLM を残すか
4. **今回の研究の新しさ**：既存の研究で済んでいることと、まだ誰もしていないこと
5. **見つからなかったこと・不確かなこと**
6. **参考文献の一覧**：1 行に 1 本。「- 著者 (年). 題名. 掲載先. 識別子」の形にする

## 守ること

- **存在を確かめられない文献は挙げない。**題名・著者・年・識別子は、検索で見た通りに書く。記憶だけで書いた文献には「（未確認）」と付ける。文献の一覧は、後で arXiv と OpenAlex で機械的に照合する。
- 数値は、論文で確認できたものだけを書く。分からなければ書かない。
- 査読済みかどうかを区別する。
- 文献の主張と、自分の解釈を分けて書く。
