## 1. 要旨

1. **H02 の「LLM の数値の予想は、渡した月の値動きの写し」は、先行研究と一致する。**
   - Chen・Green・Gulen・Zhou（2024）は、LLM のリターン予想が直近の成績を外挿しすぎ、楽観に寄ることを示した。プロンプトでは消しにくいとも報告している。
   - Bybee（2023）も、LLM が生成した期待は外挿的で、将来のリターンと負に相関するとした。
   - 数値の予想をやめる方針は、文献からも支持される。
2. **H07 で、成績を見せると一律に強気に寄った結果も、同じ方向の報告がある。**
   - LLM の予想は、もともと楽観に寄る（Chen ほか 2024）。
   - GPT で動くエージェントは強気に偏る（StockAgent、2024）。
   - ただし「成績のフィードバックで楽観が強まる」ことを直接調べた研究は、見つからなかった。ここは今回の結果の新しい点になりうる。
3. **元論文（Lee ほか 2025）は「回答のばらつき＝Ω」とした。H04 では、ばらつきは誤差の「大きさ」としては使えず（確信が強すぎ、外れの 2 乗の約 8 分の 1）、「外れやすさの順番」の手がかりにはなった（偏順位相関 +0.17）。**金融の予想でこれを直接測った研究は見つからなかった。
   - 一般の LLM では、言葉で述べた自信は過信に寄る。複数の回答の一致度のほうがやや良い（Xiong ほか、ICLR 2024）。
   - 「順番には使えるが、大きさは較正が要る」という H04 の結果は、この一般の知見と同じ形である。金融で示した点は報告に値する。
4. **2023 年以前の文章の扱いは、文献を見ると「匿名化で使う」より「時点を区切ったモデルを使う」が筋である。**
   - Lopez-Lira・Tang・Zhu（2025）は、期限より前では LLM が経済の数値を記憶から再現できることを示した。社名や日付を伏せても、わずかな手がかりから復元されて防げないという。
   - 一方、Glasserman・Lin（2024）は、匿名化した見出しのほうが成績がよかったと報告した。社名が気を散らす効果のほうが、先読みの効果より大きかったという。匿名化の効果は、題材で変わる。
   - 解決策として、年ごとに学習を区切ったモデルが公開されている。ChronoGPT-Instruct は 1999〜2024 年の年ごとの版が Hugging Face にあり、大きさは 1.55B、文脈は 1,792 トークンで、この PC の 8GB の GPU で動く。
   - 先読みの度合いを測る検定（Gao・Jiang・Yan 2025 の Lookahead Propensity）も出ている。
   - **これで、GPT 案と Gemini 案の対立に第 3 の道ができる。**期限より前の期間は、時点を区切ったモデルで読む。gpt-4o-mini は前向きの検証に使う。
5. **決算発表文の LLM の読み取りが短期のリターンを説明する証拠は、すでに査読済みの論文にある。**
   - Siano（2025）は、決算発表文の LLM による測度が、発表の短い期間のリターンの変動を、辞書や LLM でない機械学習の 3 倍説明するとした。
   - Meursault ほか（2023）は、決算説明会の文章から作った驚き（SUE.txt）によるドリフトが、数値の PEAD より大きく、近年も残るとした。
   - したがって、問うべきは「文章に情報があるか」ではない。**「発表の後の取引できる期間（翌日以降）に残るか」と「数値の驚きを統制した後に残るか」**である。H06 の IC +0.033 が統制後に有意でないことと矛盾しない。
6. **イベントの評価には、同じ日の発表どうしの相関の補正が必要である。**
   - Kolari・Pynnönen（2010）によれば、発表が同じ日に集まると、弱い相関でも検定が大きく過大に棄却する。決算発表は同じ週に集中する。
   - 発表の時刻も重要である。悪いニュースは引け後・忙しい日に出やすい（deHaan・Shevlin・Thornock 2015）。GPT 案の時刻の監査は、文献の裏づけがある。
7. **効果は、公表や時間とともに小さくなる。**
   - 公表された予測変数のリターンは、標本の外で 26%、公表の後で 58% 下がる（McLean・Pontiff 2016）。
   - LLM の見出しの戦略も、LLM の普及とともにリターンが下がっている（Lopez-Lira・Tang の 2025 年の版）。
   - 意味のある最小の効果を、既存の論文の値から決めないほうがよい。
8. **BLM に LLM のビューを入れる研究は増えているが、検証は弱い。**
   - Lee ほか（2025、CIKM）のほか、2026 年にもプレプリントがある。
   - 置換の対照、検出力、先読みを扱った研究は見つからなかった。**今回の検証の枠組み（置換の対照、較正した Ω、TE の上限）そのものが新しさになる。**
9. **取り下げに注意する。**
   - プロジェクトの資料が引いている Kim・Muhn・Nikolaev（2024）は、arXiv で取り下げられている（2025-02）。共著者が、データと分析の不整合を見つけたためである。
   - 総合報告書、19b 章、実験仮説、実験結果レポートの引用を直す必要がある。

  - gpt-4o-mini で期限より前を使う場合は、Gao ほかの LAP の検定を関門にする。匿名化の前後の順位相関（Gemini 案）より直接の検定である。
  - **gpt-4o-mini（期限 2023-10）は、2023-11 以降と前向きの検証に限って使う。**

- **今回との対応**
  - H06 の IC +0.033 は、Siano・Meursault ほかが示した「文章には情報がある」と整合する。
  - 今回の目的変数は、翌日以降のリターンだった。発表日の反応ではない。Siano の大きな効果は、主に発表日（取引できない初動）のものである。ドリフトの部分が小さいのは自然である。
  - 数値を統制すると有意でなくなった点は、Meursault ほかの「文章による驚きは数値の驚きを超える」と比べると弱い。これは、標本の大きさ（2023-11〜の約 2 年）と検出力の問題として解釈できる。
- **方針への含意**
  - 目的変数を 2 つに分ける。
    1. 発表の初動（引け後の発表なら翌日の始値〜終値も含む）：文章の読み取りが正しいかの確認。効果が大きく、検出しやすい。
    2. 翌々日以降のドリフト：取引できる価値。
  - LLM を使わない対照は、Loughran–McDonald の辞書、FinBERT（Huang ほか）、TF-IDF の正則化回帰にする。Meursault ほかの SUE.txt も正則化ロジスティック回帰なので、TF-IDF の対照は文献と比べやすい。
  - 統制に入れる数値の驚きは、SUE（XBRL から計算）にする。

### 2.5 LLM の不確実性の表現

| 著者（年） | 題名 | 掲載先 | 識別子 | 要点 |
|---|---|---|---|---|
| Xiong ほか (2024) | Can LLMs Express Their Uncertainty? An Empirical Evaluation of Confidence Elicitation in LLMs | ICLR 2024（査読済み） | arXiv:2306.13063 | 言葉で述べた自信は過信に寄る。複数の回答の一致度などを組み合わせると、いくらか改善する |
| Lee, Kim, Kim, Lee (2025) | LLM-Enhanced Black-Litterman Portfolio Optimization | CIKM 2025 | arXiv:2504.14345 | 元論文。回答のばらつきを、ビューの不確実性として使う |

- **今回との対応**
  - H04 では、ばらつきをそのまま Ω にすると確信が強すぎた（外れの 2 乗の約 8 分の 1）。一方で、ボラティリティを統制しても、外れの大きさと偏順位相関 +0.17（t 12.9）を持った。
  - Xiong ほかの「一致度は正しさといくらか対応するが、過信に寄る」と同じ形である。ただし、Xiong ほかは分類の問題についてで、連続のリターンの誤差ではない。
  - 実験結果レポートの注記のとおり、統制したのは過去 252 日のボラティリティである。LLM が見た 1 か月の散らばりをなぞっただけの可能性は残る。
  - 金融の予想で直接測った研究は、見つからなかった。
- **方針への含意**
  - ばらつきを、そのまま Ω の大きさに使うことはしない。
  - 使うなら、二段階にする。Ω の大きさは過去の誤差で較正し、銘柄の間の比率だけをばらつきの順位で変える（実験結果レポートの推奨、GPT の案と同じ）。
  - ただし、新しい構成で LLM に数値を答えさせないなら、この使い道はなくなる。報告では、元論文の前提への検証の結果として残す。

Finance 23(1)（査読済み） | doi:10.1080/1351847X.2014.953699 | 多資産（1993〜2011）で、BLM が 1/N・平均分散・最小分散より標本外のシャープレシオが高い。推定誤差と回転率が小さいため |
| Lee, Kim, Kim, Lee (2025) | LLM-Enhanced Black-Litterman Portfolio Optimization | CIKM 2025 | arXiv:2504.14345 | 元論文。LLM ごとの投資の「癖」が成績を決めるとする |
| Florencio (2026) | Grounding Investor Views: Neural Predicates in the Black-Litterman Model | プレプリント | arXiv:2607.20533 | 出力の分布のエントロピーから、ビューの不確実性を決める案 |

- **今回との対応**
  - 「Ω を過去の当たり具合で較正する」という H04 の設計は、Chen・Lim（2020）の考え方と同じ方向である。報告で根拠として引ける。
  - BLM の利点として文献が挙げるのは、推定誤差と回転率の小ささである（Bessler ほか）。これは、ビューに情報がないときでも残る利点である。H04 で、置換したビューでも BLM が壊れなかったことと整合する。
- **方針への含意**
  - BLM の役割は「信号の価値を増やす」ではなく、「信号が弱いときの損を小さくし、回転を抑える」と位置づける。
  - そのうえで、GPT 案の比較（単純な順位の戦略と BLM）を残す。比べるのは、回転率とコスト控除後の成績にする。

## 3. 意見が分かれた論点への文献からの判断

| 論点 | 文献が支持する方向 | 確かさ |
|---|---|---|
| 期限より前の文章を匿名化して使う（Gemini） | **支持しない。**Lopez-Lira・Tang・Zhu は、伏せても復元されるとした。Sarkar・Vafa は、プロンプトの対策に限界があるとした。代わりに、時点を区切ったモデル（ChronoGPT、DatedGPT）と LAP の検定（Gao ほか）が出ている | 高い（複数の独立な研究が同じ方向） |
| 前向きの検証（GPT・Claude） | **支持する。**先読みのない唯一の確実な方法である。ただし、金融の研究で事前登録した例は見つからなかった。新しさになる | 中（直接の先例が少ない） |
| 意味のある最小の効果 | 既存の値は使いにくい。Siano・Meursault の効果は、主に初動か、決算説明会の文章である。公表の後に効果は約半分になる（McLean・Pontiff）。**検出力の実験（Claude 案の合成信号）で決めるほうがよい** | 中 |
| LLM を使わない対照 | **辞書（Loughran–McDonald）、FinBERT（Huang ほか）、TF-IDF の正則化回帰（Meursault ほかと同じ型）の 3 つ。**さらに、時点を区切った ChronoBERT の埋め込みと回帰を加えると、He ほかと直接比べられる | 高い |
| BLM を残すか | **残す。ただし役割を変える。**BLM の利点は推定誤差と回転の小ささ（Bessler ほか）で、信号を作ることではない。単純な順位の戦略との比較（GPT 案）は、回転率とコスト控除後で行う | 中 |

## 4. 今回の研究の新しさ

- **すでに済んでいること**
  - LLM の数値の予想の外挿（Chen ほか）。
  - LLM の文章の点数の予測力（Lopez-Lira・Tang、Siano）。
  - 先読みの問題とその検定（Lopez-Lira・Tang・Zhu、Gao ほか）。
- **まだ誰もしていないこと**（今回の調査の範囲で見つからなかったもの）
  1. 元論文（LLM×BLM）の前提を、置換の対照で検証した研究。「ばらつきは大きさには使えず、順番にだけ使える」（H04）や、採用率 99.9% の指摘（H01）がこれに当たる。
  2. 成績のフィードバックで、LLM の予想が一律に楽観にずれることの測定（H07）。
  3. 決算発表文の LLM の点数を、時点を区切ったモデル・前向きの検証・LLM を使わない対照の 3 つで同時に確かめる設計。
  4. BLM を「信号を安全に採用する仕組み」として、合成信号で評価すること。

## 5. 見つからなかったこと・不確かなこと

- 金融の予想で、回答のばらつきと誤差の大きさの関係を測った研究。
- 8-K の EX-99.1 を LLM で読んで、翌日以降のドリフトを数値の驚きの統制つきで調べた研究。Siano は短い期間、Hadlock ほかは発表の直後を入れた予測で、完全には一致しない。
- Chen・Kelly・Xiu の「Expected Returns and Large Language Models」は、講演の記録で存在を確かめた。ただし、正式な識別子（SSRN など）を確かめられなかったので、表に入れなかった。
- DatedGPT の重みが公開されているか（デモのサイトのみ確認）。
- ChronoGPT の 1,792 トークンの文脈で、決算発表文をどこまで読めるか。実際に試す必要がある。
- Look-Ahead-Bench と 2602.14233・2604.24668・2607.20533 は、要旨しか読んでいない。2026 年のプレプリントで、査読の状況は不明である。
