# 資料集の案内

LLM-BLM の文書（報告書、実験のレポート、方針、文献調査、設計書、解説）を置く場所。コードと実験の結果のデータは、リポジトリの `experiments/` と `過去のコードと記録/` にある。

TeX の文書は、その文書のフォルダで `tectonic -X compile <名前>.tex` を実行すると PDF が作り直せる（図は同じフォルダの `*_図/` か `図/`、図を作るスクリプトは `作成スクリプト/`）。

## まず読むもの

| 知りたいこと | 読む文書 |
|---|---|
| 全体の流れと結論 | `01_総合報告書/総合報告2/LLM-BLM_総合報告書2.pdf`（10/14〜18）、その前は `総合報告1/`（〜10/13） |
| 今の結論（LLM は決算発表文を読めるか） | `02_実験/実験2_決算発表文/LLM-BLM_実験2.pdf` |
| 次にやること | リポジトリの `やること.md`、総合報告書 2 の第 15 章 |
