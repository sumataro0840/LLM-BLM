LLM-BLM 実験記録

実験のまとめ

2026年10月13日に行った7つの実験と確認の記録です。LLM は gpt-4o-mini、データは LLM-BLM/data/blm.sqlite です。

要点

  1. gpt-4o-mini は、渡した数字を「答えの元」として使います。入力を日次リターンの列から要約に変えても、予想は直近1か月のリターンをなぞりました（順位相関 +0.5 前後）。
  2. ファンダの数字は、ほとんど使われません。PER・ROE などを渡しても、予想の変化は「同じ質問を2回したときのぶれ」と同じ程度でした。
  3. 業種の特性を踏まえて数字を割り引いている証拠は、ありませんでした。REIT と、ふつうの業種で、反応に差がありません。
  4. 「考慮する比率」を明言すると、予想の桁が壊れます。渡した数字をそのまま重み付きで足すようになり、日次 1% を超える回答が 2% から 40% に増えました。
  5. 自作したセクターの指標は、運用会社のスコアカードとよく一致しました（モメンタムの相関 0.88〜0.96、ボラティリティ 0.97）。
  6. レポートの表の数字を LLM に読ませると、1〜2割の誤りが残ります。要約の文章は使えそうです。
  7. 3ターンの会話にしても、なぞりは減らず、強まりました（実験 F）。モデル自身が「1か月先はモメンタムと直近のリターンで見る」と答え、そのとおりに予想しました。
  8. 銘柄の数字を渡さず、リスクの種類ごとにプレミアムの有無を聞いても、渡した数字に沿って答えました（実験 G）。7種類のリスクの点数はそろって動き、直近1か月の S&P500 のリターン（市場リスクで順位相関 +0.77）と VIX（−0.59）に沿っていました。セクターの点数はセクターのモメンタムに沿い（+0.72〜0.75）、翌月の実際の成績とは合いませんでした（月ごとの順位相関の平均 −0.13）。

2実験 A：レポートの読み取り

目的：大和アセットの月次レポート（PDF、39本）から、見通しの数字と要約を gpt-4o-mini に取り出させ、どこまで正しいかを確かめる。

方法：PDF の先頭10ページをそのまま API に渡し、24項目を JSON で返させました（実行番号 2）。PDF の文字から決まった形で読める行（S&P500 の行、GDP の行）を答えとして、回答と照らしました。

項目一致補足
米 GDP 成長率（今年）16 ／ 18
米 GDP 成長率（来年）15 ／ 18
S&P500 の予想値（今年末・来年末）20本中 12〜13不一致のうち4本は答えの側の誤り（11・12月号は表の列が1つずれる）。実際は 16〜17 本が正しい見込み
S&P500 の直近値5 ／ 205本は答えなし。ほかは別の数字を拾った
政策金利、米10年金利—手で確かめた2本で誤りあり（5.25〜5.50 を 5.0 と回答、予想値ではなく直近値を回答）
見通しの判断（弱気〜強気）—同じレポートで −1 と 0 に分かれた（2025年6月号の米国経済。正しくは −1）
  • 年の取り違え：最初の版では GDP を1年ずれて読みました。プロンプトに「何年何月号か」を入れて減らしましたが、なくなってはいません。
  • セクターの見通し：レポートが触れているセクターが少なく、最も多い情報技術でも39本中10本でした。
  • 費用：1本あたり入力が約1.4万トークン。39本で数円程度の見込みです。

結論：予測の入力に使うのは、要約（us_summary）と主なリスク（key_risks）だけにします。表の数字を使うなら、LLM ではなく PDF の文字から決まった形で取り出すべきです。

4実験 C：決算の古さ

目的：判断日に使える最新の決算が、どのくらい古いことがあるかを測り、「古すぎる」の線を決める。

方法：評価する30か月 × 構成銘柄（14,688件）について、判断日までに提出された最新の四半期を調べました。

測ったもの中央の値95% がこの範囲99% がこの範囲最大
決算期末から判断日までの日数89日123日以内152日以内487日
期末から提出までの日数32日55日以内59日以内112日
  • 150日を超えるのは約1%（165件、93銘柄）。原因は、実際に提出が遅れた会社（Super Micro Computer など）と、データの欠けの2種類でした。
  • 不具合を1つ見つけて直しました。同じ四半期の純利益に2種類の項目名があるとき、翌年の決算書に比較用として載った値を選んでしまい、提出日が約1年遅く記録されていました（例：APA）。「最初に提出された値を優先する」に変えました。
  • 直せなかった欠け：2026年4〜6月期の決算が、57銘柄で SEC のデータ自体にありません。2026年8月末と9月末は、約12%の銘柄でファンダが空になります。

結論：決算期末から150日を超えた銘柄は、ファンダの指標を作りません（FUNDAMENTALS_MAX_AGE_DAYS=150）。

7わかったことと次の実験

数字を渡すと、数字をなぞる

リターンを渡せばリターンを、成長率だけを渡せば成長率をなぞります。既存手法の弱点（予想と入力月の平均リターンの相関 0.89）は、入力の形を変えても残りました。

「率」の形をした数字だけが使われる

リターンや成長率のように、答えと同じ形の数字は使われます。PER・ROE のような水準の指標は、どの条件でも使われませんでした。

知識はあっても、使われない

業種の知識は、説明させれば出てくるはずです。しかし、数字の表から数字を1つ返す形では、その知識が働いた形跡がありません。

入力をそろえる利点は残る

LLM に渡す数字と、比較用の統計モデルに入れる数字は、同じテーブル（stock_metrics）から取ります。差が「モデルの差」だと言えるようにするためです。

次に試す案

案内容ねらい
段階で答えさせる「強い売り〜強い買い」の5段階で答えさせ、リターンへの換算はこちらで行う入力の数字と答えの単位を別にして、足し算でなぞれなくする
数字を言葉に直して渡す「直近1か月のリターン：セクター内で上位20%」のように、順位と言葉だけを渡すなぞれる数字を入力からなくす
直近1か月のリターンを外すなぞりの元になっている1項目を入力から外すほかの情報が使われるかを見る
理由を書かせてから答えさせる数字の前に短い理由を出力させるファンダや業種の知識が使われやすくする（出力の費用は増える）

上の2つを組み合わせた条件を足して、今回と同じ規模（数百リクエスト）で比べるのがよさそうです。

結果を読むときの注意

  • 規模が小さい。実験 D は5つ、実験 E は3つの判断日だけです。傾向は読めますが、相関の細かい大小は当てになりません。
  • 相関は「判断日ごとの順位相関の平均」です。銘柄間で、予想の高低と指標の高低がどれだけそろうかを表します。予想が当たったかどうかは、見ていません。
  • 30個の平均にもぶれがあります。同じ質問を2回すると、予想の平均は 0.05% 前後ずれました。それより小さい差は、効果とは言えません。
  • モデルは gpt-4o-mini だけです。ほかのモデルで同じ結果になるかは、確かめていません。
  • 実験 A の答えは完全ではありません。位置で決めた答えが、11・12月号でずれることがわかっています。
