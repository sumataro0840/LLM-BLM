どこが評価されるか：観点と、示せること

この研究を授業の課題として出すときに、評価につながる点を8つの観点で整理します。観点ごとに、示せること、その根拠、今の状態をまとめます。

関連資料これから作るものは LLM-BLM_今後の計画.html、データの作り方と注意点は LLM-BLM_データの扱い方.html、テーブルの定義は LLM-BLM_DB設計.html にあります。

授業の採点基準は分からないので、研究の課題で一般に見られる観点で整理しています。基準が分かったら、それに合わせて見直してください。

批判的な読み、設計、データ、比較、説明、再現性、限界、拡張
見せ場は設計
未来の情報が漏れる経路を、1つずつふさいだこと
3〜4 割が完了
データの土台と LLM の予想まで。段階1〜3 はこれから
勝ち負けは中心にしない
成績より、検証の確かさで評価される形にする

段階は絞らず、3つとも進める前提で書いています。段階ごとに「何を残せば評価につながるか」は、11章にまとめています。

3元の研究の問題点

元の実装をそのまま動かすのではなく、再現する過程で問題を見つけて直しています。レポートでは「問題 → 影響 → 直し方 → 直した結果」の形で書けます。

見つけた問題影響対処状態
プロンプトは「percentage change」と言いながら、小数（0.0016）を渡しているパーセントで答えた回答が混ざると、ばらつき（予想の信頼度）が大きく狂う小数であることを明記し、例を示した。約44万個の回答で、桁の取り違えは見当たらない済み
構成銘柄が、実行した時点のもので全期間固定後から指数に入った銘柄を、過去にさかのぼって使っている（先読み）各月末に在籍していた銘柄だけを対象にした済み
共分散を、その月の約20日分だけで計算している銘柄数（約500）に対してデータが足りず、最適化が正しく解けない直近1年の日次リターンと、縮小推定を使う段階1
最適化が、最適解に届く前に止まる3つの月で確認。元の結果は実質 6.7〜8.3 銘柄だが、同じ目的関数の正しい解は 3.6〜4.5 銘柄。「分散された比率」は途中で止まったことによる二次計画用の解法に替えた。元の設定のままの結果も残して比べた（段階1の結果）段階1
均衡リターンの計算で、日次のリターンから年率の無リスク金利（0.02）を引いている均衡リターンが1日 -0.7〜-1.7% という、あり得ない値になる。ただし予想が強く信じられる設定なので、結果への影響は小さい時価総額の比率から逆算する標準の式にし、金利は日次に直して使う段階1
株価の取得で、月末日が抜けている毎月1日分のリターンが欠ける終了日を1日延ばして取得済み
月の最初の日のリターンが入力に入らない入力が1日分少ない前月末の終値から計算済み
ティッカーの書き方の違い（BRK.B と BRK-B）一部の銘柄の株価が取れないyfinance の書き方に統一済み
同じ質問を30回送っている全銘柄では1か月分に約7時間かかる1回の質問で30個の回答を受け取る形にした（1か月分が数分）済み
LLM の回答のばらつきを、そのまま予想の信頼度に使っているばらつきは実際の予測誤差の 1/10〜1/20 で、ほとんど当たらない予想を強く信じる設定になる。計算を正しくすると、比率が1〜2銘柄に集中する未対応。指数からのずれに上限を付けるか、当たり具合に合わせて予想を縮める段階1
強くするには：段階1で、「元の設定のまま」と「直した設定」の両方で比率を計算し、結果がどれだけ変わるかを数字で示します。指摘だけでなく、影響の大きさまで示せると説得力が上がります。

4実験の設計

過去のデータで戦略を試すとき、判断した時点では知り得なかった情報が混ざると、成績が実力より良く見えます。この研究の一番の見せ場は、その経路を1つずつ挙げてふさいだことです。

経路ふさぎ方証拠として示せるもの状態
① モデルの知識知識の期限（2023年10月）が評価期間（2024年4月〜）より前のモデルを使う。プロンプトに日付を入れない使ったモデルの版と、プロンプトの全文（llm_runs）済み
② 渡す資料公表日が判断日以前の資料だけを使う。AI に検索させず、渡した資料だけを整理させる資料ごとの公表日。検索して書かせた試作に、後の情報が混ざっていた実例段階2・3
③ 構成銘柄判断日に在籍していた銘柄だけを対象にする在籍期間のテーブル。各月の対象銘柄数済み
④ 財務データの提出日提出日が判断日以前の値だけを使う。最初に提出された値を保存提出日の分布（期末から中央値で34日）。同じ四半期がそろうまでの推移済み 利用は段階2・3
⑤ 株価と共分散判断日までのデータだけを使う入力と共分散の計算期間済み段階1
⑥ 設定やモデルの選び方選ぶ期間と、成績を示す期間を分ける。変数は評価期間より前のデータで選ぶ期間の区切りと、変数を選んだ手順段階1段階2・3
強くするには：漏れの影響を測る実験を行います。同じ月について、検索して書かせたレポート（未来の情報が混ざる）と、当時の資料だけから作ったレポートを入力にして、成績を比べます。差が出れば、「漏れをふさぐこと」の意味を数字で示せます。

6比較の公平さ

示すこと内容状態
比べる相手を複数用意する時価総額加重（元の S&P500）、等金額、平均分散、Black-Litterman（LLM の予想あり）段階1
全戦略に同じ条件を適用する同じ銘柄、同じ期間、同じ除外、同じ共分散段階1
成績を複数の指標で見るリターン、リスク、シャープレシオ、下落リスクに対するリターン、元の指数との差段階1
配当の扱いをそろえる戦略は配当込みの株価で計算している。配当を含まない指数（^GSPC）とそのまま比べない段階1
統計モデルと比べる同じ変数を渡したロジスティック回帰と比べ、LLM が何を足しているかを示す段階2・3
選ぶ期間と示す期間を分ける設定やモデルを選んだ期間の成績を、そのまま成果として示さない段階1段階2・3

7結果の説明

知りたいこと方法状態
LLM の予想は、どんな性質か予想と実際のリターンの比較。最初の確認では、予想は楽観的（1日 +0.18% に対して実際は +0.02%）で、銘柄の順位はほとんど当たっていない（順位相関 +0.05）済み 最初の確認
比率の差のうち、何が成績に効いたかセクターの配分の差と、セクター内の銘柄の差に分解する段階2・3
どの入力が予想を良くしたか入力のまとまり（値動き、財務、市場環境、文章）を1つずつ足した実行を比べる段階2・3
どの変数が統計的に効いているかロジスティック回帰の検定（カイ二乗検定の一種）段階2・3
漏れは、成績をどれだけ良く見せるか未来の情報が混ざった入力と、当時の情報だけの入力を比べる段階2・3
なぜ良かったか・悪かったかの説明上の数字と当時のレポートを LLM に渡して、文章にまとめさせる。計算はさせない段階2・3

LLM に「理由」や「寄与率」を直接答えさせないことも、評価できる点です。LLM の自己説明は、実際の挙動と一致するとは限らないためです。

8再現性

示せること内容
実行の条件を残しているモデルの版、プロンプトの全文、temperature、回答の数、期間の長さを、実行番号ごとに保存
結果を加工せずに残している平均や分散だけでなく、30個の回答をすべて保存。後から別の集計ができる
途中で止まっても再開できる銘柄ごとに保存し、同じ実行番号で続きから動かせる。設定が違う実行には書き込まない
コードが役割ごとに分かれているデータの取得・加工・保存（marketdb/）と、LLM（llm/）を分離。互いに依存する向きは一方通行
設定が1か所にあるすべて .env で指定
資料があるテーブルの定義、データの作り方、計画、確認用のノート
限界：LLM の回答は、同じ設定でも実行のたびに変わります。「同じ数字を再現できる」のではなく、「保存した回答から同じ結果を再計算できる」という意味の再現性です。株価も、取得する時期で調整後の値が変わります。

9限界の明示

限界を自分で挙げて、結論への影響を述べていることは、それ自体が評価の対象になります。

限界結論への影響
評価は30か月分だけ差が出ても、偶然と区別できない場合が多い。差の大きさと、そのぶれの幅を一緒に示す
除外した28銘柄（生存者バイアス）破綻・買収された銘柄が入っていない。全戦略に同じ除外を適用しているので、戦略同士の比較は公平
構成比率は近似浮動株で調整していない。年1%未満の差は、近似による差と区別できない
社名・セクターは現在のもの当時の名称・分類と違う場合がある
売買のコストを入れていない毎月比率を変える戦略は、実際にはコストの分だけ成績が下がる
モデルは1つだけ結果が、gpt-4o-mini に固有のものかどうかは分からない
相場の局面が偏っている期間全体で指数が大きく上がっている。下落相場での挙動は分からない

10独自の拡張

拡張元の研究との違い評価につながる理由
セクターの予想を Black-Litterman に入れる元は個別銘柄ごとの予想だけBlack-Litterman 本来の使い方（ポートフォリオ単位の予想）で、セクター内の調整が計算から自動的に出る
入力を足す（財務、市場環境、文章）元は1か月分のリターンと社名・業種だけ入力ごとの効果を切り分けて示せる
市場が織り込む情報と組み合わせる元は過去のデータだけ期待リターンは均衡から、変動の大きさは VIX から、金利の見通しは国債利回りから取り、LLM にはそこからのずれを答えさせる、という一貫した考え方になる
結果へのフィードバック元にはない数字で出した寄与と、当時の資料を結びつけて説明する
統計モデルとの比較元は LLM 同士の比較「LLM は何を足しているのか」という、より根本的な問いに答えられる
漏れの影響を測る実験元にはない設計の意味を、数字で示せる

11段階ごとに残すもの

3つの段階をすべて進める場合に、各段階で残しておくと評価につながるものです。後から作り直すのは難しいので、進めながら残します。

段階残すものつながる観点
1 比率の調整「元の設定のまま」と「直した設定」の、両方の結果① 批判的な読み
4つの戦略の成績表（複数の指標）と、累積リターンのグラフ④ 比較
共分散の作り方を変えた場合の比較（過去だけ、VIX で調整）⑧ 拡張
設定を選ぶ期間と、成績を示す期間の区切りを、結果を見る前に決めた記録② 設計
2 フィードバック月ごとの要因分解の表⑤ 説明
集めたレポートの一覧（発行元、対象月、公表日）② 設計
LLM に渡した数字と、返ってきた説明の例⑤ 説明
3 セクターの予想変数を選んだ手順と結果（使った期間、残った変数、検定の結果）② 設計、⑤ 説明
入力のまとまりごとの成績表⑤ 説明
ロジスティック回帰との比較④ 比較
漏れの影響を測る実験の結果② 設計

12評価を下げかねない点

点内容備え
結果が良すぎる指数を大きく上回る成績は、まず漏れか計算の誤りを疑われる漏れの経路の表を先に示す。良い結果ほど、確認した内容を詳しく書く
「勝った」ことを結論にする30か月では、統計的に強いことは言えない結論は「この設計で、こう検証した結果、こうだった」にする。勝てなかった場合も、理由と、入力を足した場合の変化を示せば成立する
作ったものが多く、筋が見えにくくなる段階を絞らない場合、何を主張したいのかが埋もれやすい主張を1つに決める（漏れをふさいだ設計）。各段階の結果を、その主張との関係で説明する
段階1が後回しになる比率の計算と比較がないと、他の段階の結果を評価できない段階1を最初に通す。ここまでで、1本のレポートとして成立する
元の研究と比べられない直した点が多く、元の結果との違いの原因が分からなくなる変更点を表にまとめる。可能な範囲で、元の設定での結果も残す
