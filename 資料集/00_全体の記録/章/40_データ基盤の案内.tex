\chapter{データ基盤の案内}\label{ch:data-guide}

この部（第 VI 部）では、研究のすべての実験が使ったデータ基盤を説明する。データ基盤は 3 回に分けて作った。

\begin{enumerate}
\item \textbf{最初の DB}（10/10〜13、総合報告書 1）：2023-03〜2026-09 の \SP{} の構成銘柄、株価、財務諸表、LLM の予想、BLM の比率、月次レポート、セクターと銘柄の指標。次の 3 章（システムの構成、データ基盤、データベースの設計）。
\item \textbf{2015 年への拡張とイベントのデータ}（10/15〜18、総合報告書 2）：DB を 2015 年までさかのぼり、決算発表文、受理時刻、驚き、点数、アナリスト予想を足した。「イベントスタディの設計」と「決算発表のデータと点数」の章。
\item \textbf{追加のデータ}（10/19）：提出書類の索引、出来高、ファクター、マクロの系列、空売りの出来高、Wikipedia の閲覧数、内部者の取引。「追加したデータ」の章。
\end{enumerate}

\begin{projbox}
\begin{itemize}
\item すべての実験は、この DB を\textbf{読み取り専用}で開く。
\item DB を大きく変える前には、日付つきの複製（\code{blm\_2015\_backup\_2026-10-17.sqlite} など）を残した。
\item API の鍵などの秘密の情報は \code{.env} に置き、コードにも DB にも書かない。
\end{itemize}
\end{projbox}
