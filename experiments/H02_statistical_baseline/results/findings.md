# H02 の判定

実行日：2026-10-16。API は使っていない。数値は `summary.json`、月ごとの値は `monthly_ic.csv`。

## 判定：支持された（LLM に固有の予測力は、あっても IC 0.03 未満）

主な検定（設計書のとおり）：LLM の予想の順位を、判断月の平均日次リターンの順位と日次リターンの標準偏差の順位で回帰した残差（入力で説明できない部分）と、翌月のリターンの順位相関。

| | 平均 | $t$ | $p$ | 95% 信頼区間 |
|---|---|---|---|---|
| LLM に固有の部分の IC | −0.004 | −0.28 | 0.78 | −0.036〜+0.027 |

信頼区間の上限が、事前に決めた意味のある最小の効果（0.03）を下回るので「支持」。

## そのほかの結果（30 か月、月平均 488.7 銘柄）

| 予想 | IC の平均 | $t$ | 95% 信頼区間 |
|---|---|---|---|
| LLM（実行 1） | +0.050 | 1.46 | −0.020〜+0.120 |
| LLM の写し（入力の平均と散らばりの回帰の当てはめ値） | +0.053 | 1.60 | −0.015〜+0.121 |
| 判断月の平均日次リターン（LLM が見た数字そのもの） | +0.053 | 1.68 | −0.012〜+0.118 |
| 短期反転（−直近 1 か月） | −0.046 | −1.51 | −0.107〜+0.016 |
| 12-1 か月のモメンタム | +0.027 | 0.83 | −0.039〜+0.093 |
| 統計モデル（12 指標のリッジ回帰、2015 年から学習） | −0.002 | −0.08 | −0.065〜+0.060 |

- 写しの決定係数は平均 0.81（順位で 0.81）。LLM の予想の 8 割は、入力の月の平均と散らばりの直線の関数で説明できる。
- LLM の予想、その写し、入力の平均そのものの IC はほぼ同じ（0.050〜0.053）。この期間に IC が少し正だったのは、直近 1 か月の値動きが（個別株の短期反転の通説とは逆に）わずかに続いたためで、LLM が足した情報ではない。
- 3 つを並べた Fama-MacBeth 回帰では、LLM の係数は −0.019（$t$ −0.54）、入力の平均の係数は +0.071（$t$ 2.10）。
- 統計モデルは評価期間では当たらなかった（IC −0.002）。統計モデルと LLM の IC の差は −0.052（$t$ −1.08）で、区別できない。
- 誤差：MAE は LLM 0.45%/日、写し 0.44%/日、「0 と予想」0.33%/日。LLM の予想の大きさは、何も予想しないより外れが大きい。方向の正解率は LLM 52.3%、統計モデル 49.5%。

## 読み方

LLM の数値予想（実行 1）は、統計的に「入力の月の平均をなぞったもの」と同じ情報しか持たない。LLM を通すことで足された予測力は検出されず、その上限は IC 0.03 程度に抑えられる。一方、30 か月では、LLM も入力の平均も、IC が 0 と区別できない。
