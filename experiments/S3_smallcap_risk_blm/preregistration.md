## 4. 共分散の 3 つの版

各リバランスの日 d に、直近 252 日の Ledoit–Wolf の共分散 Σ（追記 1 と同じ）を作り、銘柄ごとの倍率 s で Σ' = S Σ S（S = diag(s)）とする。倍率は、d 以前の 60 取引日以内に反応日がある発表を持つ銘柄（「発表の後の銘柄」。最新の発表を使う）にだけかける。ほかの銘柄は s = 1。

- **A 基準**：s = 1（追記 1 と同じ）。
- **B 株価で補正**：d より前に 60 日の窓が閉じた 2015 年以降のすべての発表（範囲の外も含む）で、`log_rv_2_60` を説明変数（`log_rv_pre`、`log_rv_long`、`log_float`、`abs_r_0_1`、`abs_sue`、`sue_missing`、`abs_rev`、`rev_missing`。S2 と同じ定義、1%/99% で丸め、欠けは 0）に回帰する。目的変数も説明変数も、年・四半期の中で平均を引いてから最小二乗（時期の固定効果と同じ。銘柄どうしの相対的な関係だけを学ぶ）。発表の後の銘柄について、予測した相対的な対数の変動率 x'β を、その日の発表の後の銘柄の中で平均を引いた値 ŷ とし、Ledoit–Wolf の対数の標準偏差も同じ銘柄の中で平均を引いた値 l として、s = exp(ŷ − l) とする。s は [0.5, 2] に丸める。学習の発表が 500 件未満なら、その日は s = 1。
- **C 株価＋テキストで補正**：B の説明変数に、リスクの点数（ChronoGPT：S2 の `chrono_risk`。四半期の中で標準化）を足す。点数がそろう学習の発表が 500 件未満の日、点数のない銘柄は、B の倍率を使う。

## 6. 主な検定

- 対象：2015 年末から、四半期ごとのリバランス、リターンの見通しは `chrono_ridge`。
- 各日 t の標準化した超過リターン z_t = (ポートフォリオ − 比べる相手の日次のリターン) / σ_ex。σ_ex は、直近のリバランスの日に、その版の Σ' で計算した事前の日次の TE（比べる相手との比率の差 a で √(a'Σ'a)）。
- 偏りの統計量 b = √(z_t² の平均)。b = 1 なら、事前の TE が実現の TE を正しく見積もっている。
- **P**：D = |log b_B| − |log b_C| > 0（C のほうが 1 に近い）か。
- 判定：日のブロックの長さ 63 の円形のブロック・ブートストラップ（B と C の同じ日を一緒に引く、2,000 回、乱数の種 0）で、D* ≤ 0 の割合を片側 p とし、p < 0.05 なら「支持」。
