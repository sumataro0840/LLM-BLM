## 読み方

1. **gpt-4o-mini は、決算発表文から「市場がどう受け取るか」を読み取れる。**
   - 点数を 5 段階に分けると、反応の平均は −1.77%、−0.20%、−0.25%、+0.46%、+1.16% と順に並んだ。上と下の差は約 2.9 ポイント（探索の確認）。
   - LLM を使わない 3 つの方法と、数値の驚きを統制しても、効果はほとんど減らない。
2. **LLM を使わない方法の情報を、LLM の点数がほぼ含んでいる**（探索の確認）。
   - 1 つずつ入れると、FinBERT（+39bp、t 3.7）、TF-IDF（+44bp、t 3.7）、SUE（+28bp、t 4.0）もそれぞれ効く。
   - LLM の点数を同時に入れると、辞書・FinBERT・TF-IDF の係数はほぼ 0 になる（t 0.4、−0.4、0.3）。
   - LLM の点数の効果は、FinBERT や TF-IDF の約 3 倍。Siano（2025）の「LLM の測度は、辞書や非 LLM の機械学習の 3 倍説明する」と合う。
3. **ただし、取引には使えない。**
   - 反応は発表の 2 日のうちに出尽くし、その後のドリフト（S1）は有意でない。
   - 取引できるのは発表の後なので、この点数で利益を出すことはできない。Wu ほか（2025）の「発表文の内容は寄り付きで完全に反映される」とも合う。
   - H06 で翌月のリターンを説明できなかったことと矛盾しない。
4. **先読みのない小さなモデル（ChronoGPT、ゼロショット）は、ほとんど読み取れない。**
   - 同じ標本 A で +4bp（t 0.4）。gpt-4o-mini の 120bp と大きな差がある。
   - 標本 B では +9bp（t 1.9）。補正の前の片側 p は 0.03 だが、Holm の補正の後は 0.089 で有意でない。
   - 1.55B のモデルを質問の形で使う方法では、点数として弱すぎる。He ほか（2025）の、内部の数値と回帰を使う方法（やること C1）で、先読みのない比べる相手を作り直す必要がある。

## 限界

- **数値の驚きの統制が弱い。**アナリストの予想がないので、SUE は前年同期との差で測った。LLM は、本文の「予想を上回った」といった記述から本当の驚きを読んでいる可能性がある。その場合、効果の一部は「数値の驚きを文章から読む力」で、純粋な語調の情報ではない。
- **期間は約 3 年（2023-11〜2026-08）だけ。**gpt-4o-mini の知識の期限より後に限ったため。
- **8-K の受理の時刻が、ニュースの配信より遅れている発表がある。**場中の受理が 32%。ただし、場中を除いても結果は変わらない（R2）。
- **ChronoGPT の弱さは、モデルの弱さか質問の形の弱さか、区別できない。**
