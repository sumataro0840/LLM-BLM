## 3. データ

  2. 本文がある。書類の種類（`doc_type`）が `EX-99` で始まる。
  3. `event_date` があり、主な窓の株価がそろう。
  4. gpt-4o-mini の点数（score run 1）がある。

- **標本 B（副）**：受理日 2016-01-01〜2023-10-31。条件は 1〜3 と 5 が同じで、4 の代わりに ChronoGPT の点数があること。

## 4. 変数

### 目的変数（主）

- `abn_r_0_1`：`event_date` の前日の終値から、`event_date` の翌日の終値まで（2 取引日）の超過リターン。
- 超過リターンは、銘柄の配当込みのリターン − 同じセクターの ETF のリターン。ETF の株価がない日は、S&P500 との差にする。
- 上下 1% で丸める（標本の全体で）。

### 主な説明変数

- `llm_composite` ＝ `tone` ＋ `outlook` ＋ `guidance_change`（null は 0）。H06 と同じ式で、学習しない。
- 標本の中で標準化する（平均 0、標準偏差 1）。

### 統制

数値の驚き
- `sue`：上下 1% で丸める。
- `revenue_surprise`：上下 1% で丸める。

LLM を使わない文章の分析（すべて標準化する）
- `dictionary_net_tone`：score run 2
- `finbert_net_tone`：score run 3
- `tfidf_pred`：TF-IDF ＋ リッジの予測
  - 固定の設定：語彙 2 万、min_df 5、alpha 10。
  - 学習には、受理日の四半期が始まる前に窓が閉じた発表だけを使う（標本 B の期間を含む）。

市場の情報
- `abn_pre`：`[-21, -1]` の超過リターン。上下 1% で丸める。
- `log_mcap`：`event_date` の前日の時価総額の対数。

固定効果
- セクター
- `event_date` の年と四半期

欠けている値の扱い
- 統制に欠けがある発表は、その変数を 0（標準化した後の平均）で埋める。
- 欠けているかどうかを表す 0／1 の変数を足す（SUE と売上の驚きだけ）。
- こうするのは、SUE がない発表を落として標本が偏るのを避けるため。

## 5. 検定と判定

- **回帰**：`abn_r_0_1` を、`llm_composite` と 4 章の統制と固定効果で回帰する（最小二乗法）。
- **標準誤差**：`event_date` ごとにまとめる（CR1。t 分布の自由度は日数 − 1）。
- **置換の対照**：同じ `event_date` の中で `llm_composite` を入れ替えて 1,000 回回帰し直す（乱数の種 0）。
- **判定**
  - 「支持」：`llm_composite` の係数の片側 t 検定で p < 0.05、かつ、置換の片側 p < 0.05。
  - 「支持されない」：それ以外。
  - 係数（1 標準偏差あたりの bp）と 95% 信頼区間を、判定にかかわらず報告する。
- **説明力**：統制だけの回帰と比べた決定係数の増分を、補助に報告する。
