# E4 事前登録：LLM の学習なしの読み取りは、反応で学習させた FinBERT を超えるか

状態：**確定**（2026-10-18）。この文書と `run.py` を同じコミットで固定してから、`run.py` を 1 回だけ実行する（`--smoke` の動作確認は、評価の回帰を行わないので除く）。実行に使ったコミットは `results/summary.json` に記録される。
この文書に書いていない分析は、すべて「探索」として別に報告する。

## 1. 位置づけ

- E2・E3 で、gpt-4o-mini の点数（学習なし）は、発表への 2 取引日の反応を、辞書・FinBERT（学習なし）・TF-IDF＋リッジ・数値の驚き・アナリスト予想との差を超えて説明した。
- 比べた相手のうち、実際の反応で学習したのは TF-IDF＋リッジ（単語の出方）だけだった。文脈を読める BERT を、反応で追加学習した専用のモデルとは比べていない。
- 問い：**LLM の学習なしの読み取りは、過去の反応で追加学習した FinBERT を超える情報を持つか。**
- 標本 A（2023-11〜2026-08）は、E2・E3 で反応を計算した期間の再利用である。

## 2. この文書を書いた時点で見たもの・見ていないもの

- **見たもの**：E2・E3 の結果。FinBERT の事前学習の文章の時期（論文によれば 10-K・10-Q は 1994〜2019 年、決算説明会は 2004〜2019 年、アナリストのレポートは 1995〜2008 年。評価期間より前）。
- **見ていないもの**：追加学習したモデルの予測と、その評価。学習も一度も行っていない。

## 3. 学習

- **元のモデル**：`yiyanghkust/finbert-tone`（E2 の FinBERT の点数と同じ版）。分類の頭を外し、出力 1 つの回帰の頭を付ける。
- **入力**：発表文の先頭 512 トークン（それより後は切る）。
- **目的変数**：E2 の基本の標本の主な窓の超過リターン（`abn_r_0_1`）。学習の標本の 1%・99% 点で丸め、学習の標本の平均と標準偏差で標準化する。
- **学習の標本**：E2 の基本の標本のうち、提出日が 2015-01-01〜2022-12-31 で、目的変数があるもの。評価の標本（2023-11 以降）と重ならない。
- **設定（固定。選び直さない）**：AdamW、学習率 2e-5、重みの減衰 0.01、2 エポック、バッチ 16（8 × 勾配の累積 2）、最初の 10% で学習率を上げ、その後は直線で下げる。bf16 の自動混合精度。乱数の種 0。検証用の分割や早期終了は使わない。
- **予測**：提出日が 2023-01-01 以降の基本の標本の発表。予測は DB に点数の付け方の 1 つ（`finbert_ft`、反応を使う）として保存する。学習したモデルは `data/cache/models/`（Git の外）に保存する。

## 4. 評価

- **標本**：E3 と同じ標本 A（5,374 本）。
- **変数**：E3 のモデル M1（E2 の統制＋アナリスト予想との差）に、追加学習した FinBERT の予測（`ft_pred`、標本の中で標準化）を加える。
- **主な検定（モデル M2）**：M1 ＋ `ft_pred` での、LLM の合成点数の係数。標準誤差は反応の日ごとにまとめ、同じ反応の日の中での置換 1,000 回（乱数の種 0）を行う。
- **判定**
  - 「支持」：LLM の係数が、片側 t 検定で p < 0.05、かつ置換で片側 p < 0.05（LLM は追加学習した FinBERT を超える情報を持つ）。
  - 「支持されない」：それ以外。

## 5. 副次の分析（Holm で 2 つを補正）

- **S1**：`ft_pred` を LLM の代わりに入れた M1（LLM なし）で、`ft_pred` の係数は正か（追加学習が働いたかの確認）。
- **S2**：M2（LLM と同時）で、`ft_pred` の係数は正か（追加学習した FinBERT は、LLM を超える情報を持つか）。

あわせて、説明力の比較として、M1 から LLM を除いたモデルに、LLM だけ・`ft_pred` だけ・両方を加えたときの決定係数の増分を報告する（検定ではない）。
