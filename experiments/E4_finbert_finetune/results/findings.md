# E4 の判定：LLM の点数は、反応で追加学習した FinBERT に置き換えられない（支持）

- **実行**：2026-10-18。事前登録（`../preregistration.md`）と `run.py` をコミット `3c8f0db` で固定してから、1 回だけ実行した。数値は `summary.json`。
- **学習**：FinBERT（`yiyanghkust/finbert-tone`、E2 と同じ版）に回帰の頭を付け、2015〜2022 年の決算発表 13,979 本の 2 取引日の反応で追加学習した（2 エポック、1,748 歩、この PC の GPU で 756 秒）。設定は事前登録で固定し、選び直していない。
- **予測**：2023 年以降の 7,524 本。DB の点数の付け方の番号 8（`finbert_ft`、反応を使う）。学習したモデルは `data/cache/models/finbert_ft_e4/`（Git の外）。
- **評価**：E3 と同じ標本 A（5,374 本、E2・E3 で一度見た期間）。統制は E3 のモデル M1（E2 の統制＋アナリスト予想との差）。

## 主な検定

| | 係数（1 標準偏差あたり） | t | 置換 |
|---|---|---|---|
| **LLM の合成点数（追加学習した FinBERT と同時、M2）** | **+102bp**（95% 区間 +77〜+128） | 7.77 | 片側 p = 0.001 |

**判定：支持。**E3 の M1 での +116bp から、追加学習した FinBERT を加えて +102bp になった（88% が残った）。

## 副次の分析（Holm で 2 つを補正）

| | 係数 | t | Holm の p |
|---|---|---|---|
| S1 追加学習した FinBERT だけ（LLM なし） | +71bp | 6.45 | < 0.001 |
| S2 追加学習した FinBERT（LLM と同時） | +34bp | 3.01 | 0.001 |

追加学習は効いた（学習なしの FinBERT は E2 で +39bp）。LLM と同時でも、追加学習した FinBERT にはまだ独自の情報が少し残る。

## 説明力の比較（検定ではない）

| 統制（M1 から LLM を除いたもの）に加えたもの | 決定係数の増分 |
|---|---|
| LLM だけ | +2.01 ポイント |
| 追加学習した FinBERT だけ | +0.84 ポイント |
| 両方 | +2.18 ポイント |

LLM の説明力は、追加学習した FinBERT の約 2.4 倍。FinBERT に LLM を足すと +1.34 ポイント上乗せされるが、LLM に FinBERT を足しても +0.17 ポイントしか上乗せされない。2 つの順位相関は 0.51。

## 探索：2 つの点数の 3 分位ごとの反応

| 追加学習した FinBERT ＼ LLM | 低 | 中 | 高 |
|---|---|---|---|
| 低 | −1.57% | −0.39% | +0.27% |
| 中 | −0.66% | −0.09% | +0.53% |
| 高 | −0.69% | +0.35% | +1.17% |

FinBERT の 3 分位を固定すると、LLM が低から高に移るにつれて、どの行でも反応が上がる（差は 1.2〜1.9 ポイント）。LLM の 3 分位を固定して FinBERT を動かしたときの差は、それより小さい（0.7〜0.9 ポイント）。

## 読み方

1. **学習なしの LLM の読み取りは、過去の実際の反応で学習させた専用のモデルより、反応をよく説明する。**深層学習で「当て方」を学ばせても、gpt-4o-mini の文章の理解には届かなかった。
2. **事前登録の解釈の注意**：2 つが同じ情報を誤差つきで測っているだけでも、両方の係数は残りうる。それでも説明力の比較では、LLM が FinBERT の情報をほぼ含み、さらに多くを持つ側にある。「LLM は追加学習した FinBERT では置き換えられない」と言える。
3. 追加学習した FinBERT は、先頭の 512 トークンしか読んでいない。LLM（gpt-4o-mini）は先頭の 15,000 字を読んでいる。差の一部は、読む量の差かもしれない。

## 限界

- 学習の設定は 1 つだけ（事前登録で固定）。もっと良い設定はありうるが、選び直すと過剰適合になる。
- 読む量（512 トークンと 15,000 字）が揃っていない。
- 標本 A は E2・E3 で一度見た期間である。
