# S2 事前登録：小型株で、決算発表文の読み取りは発表後の変動率（リスク）を予測するか

状態：**確定**（2026-10-24）。この文書と `run.py` を同じコミットで固定してから、`run.py` を 1 回だけ実行する（`--dry` は株価の代わりに乱数を入れた動作の確認で、どの変動率も計算しない）。実行に使ったコミットは `results/summary.json` に記録される。この文書に書いていない分析は、すべて「探索」として別に報告する。

利用者の依頼（2026-10-24）：S1 の次に、LLM にリスクを予測させる。

## 1. 位置づけ

- S1：小型株で、ChronoGPT＋リッジの読み取りが発表後 2〜60 日のドリフトを予測した（支持）。しかし、規模で加重した月次のポートフォリオでは有意な差にならなかった。
- リターンの平均より、変動率のほうが予測しやすい（変動率の持続、GARCH・HAR）。文章の不確実さ・否定的な語が、その後の変動率と関係するという研究がある（Loughran・McDonald 2011 など）。
- 問い：**決算発表文の読み取りは、過去の変動率と 2 日の反応の大きさを超えて、発表後 2〜60 取引日の変動率を予測するか。**
- 予測できれば、BLM の見通しの不確かさ（Ω）や量の調整に使える（この実験では検定しない。後の追記で扱う）。

## 2. この文書を書いた時点で見たもの・見ていないもの

- 見たもの：S1 のすべての結果（`experiments/S1_smallcap_drift/results/`。点数と、符号つきの超過リターン：2 日の反応・2〜21 日・2〜60 日・22〜60 日の関係、点数の 5 分位ごとの符号つきの平均）。S1 の panel の `abn_r_0_1` の値。
- 見ていないもの：どの銘柄の、どの期間の変動率も計算していない。点数と変動率、点数と反応の**大きさ**（絶対値）の関係は、一度も計算していない。

## 3. データ

- S1 と同じ（`data/smallcap.sqlite` の 1,000 社、2015-01-01 以降に提出された決算発表文、同じ銘柄・同じ反応日は最も早いものだけ）。評価する発表は、2020-01-01 以降に提出され、提出日に小型株の範囲にいた会社のもの（S1 と同じ定義）。2015〜2019 年の発表は学習にだけ使う。
- 株価：`prices` の調整後終値。日次の対数リターン。株価が欠けた日のリターンは欠けとする。

## 4. 変数

### 目的変数（反応日を day 0 とする）

- 主：`log_rv_2_60`：2〜60 取引日目の日次の対数リターンの標準偏差（年率、√252 倍）の対数。59 日のうち 40 日以上のリターンがあるものだけ。
- 副：
  - `log_rv_2_21`：2〜21 日目（20 日のうち 15 日以上）
  - `log_ivol_2_60`：2〜60 日目の、銘柄と IWM の日次の対数リターンの差の標準偏差（年率）の対数（40 日以上）
  - `abs_r_0_1`：2 日の反応の大きさ `|abn_r_0_1|`（S1 と同じ IWM との差）
- 上下 1% で丸める（評価する標本の中で）。

### 統制（発表の時点、または day 1 の終値の時点で知られているもの）

- `log_rv_pre`：$-60$〜$-1$ 日の変動率（年率）の対数（40 日以上）
- `log_rv_long`：$-252$〜$-61$ 日の変動率の対数（120 日以上。欠けは `log_rv_pre` で埋め、欠けの印を足す）
- `log_float`（S1 と同じ）、`abs_sue`（|SUE|、欠けは 0 と欠けの印）、`abs_rev`（|売上の驚き|、同じ）
- 主と、`log_rv_2_21`・`log_ivol_2_60` の回帰には `abs_r_0_1`（day 1 の終値で分かる 2 日の反応の大きさ）も入れる。`abs_r_0_1` を目的変数にするときは入れない。
- 業種（SIC の上 2 桁、50 本未満はまとめる）と年・四半期の固定効果。標準誤差は反応日ごとにまとめる。

### 点数（評価する標本の中で標準化。どれも「高いほどリスクが高い」向きに定義する）

| 列 | 中身 | 学習 |
|---|---|---|
| `chrono_risk` | ChronoGPT 版 2015、元の文章の最後の層の平均（S1 の `chrono_ridge` と同じベクトル）に、四半期ごとのリッジ（E5 の `rolling_ridge`）。正解は `log(rv_2_60 / rv_pre)`（変動率の驚き）、60 日の窓がその四半期の前に閉じた発表だけで学習 | 変動率の驚き |
| `chrono_mid_risk` | ChronoGPT 版 2015、掃除した文章の 26 層目の平均に、同じリッジ | 変動率の驚き |
| `dict_uncertainty` | Loughran–McDonald の不確実さの語の割合 | なし |
| `dict_negative` | Loughran–McDonald の否定的な語の割合 | なし |
| `finbert_negative` | FinBERT の否定的な文の割合 | なし |
| `gpt_flags` | gpt-4o-mini のリスクの印 10 個の数 | なし |
| `gpt_risk` | gpt-4o-mini の 14 の項目（S1 の `gpt_ridge` と同じ）に、同じ四半期ごとのリッジ。正解は変動率の驚き | 変動率の驚き |

## 5. 主な検定

- **P**：評価する発表（2020 年以降、範囲の中）で、`log_rv_2_60` を `chrono_risk` と統制と固定効果で回帰した `chrono_risk` の係数が正か。
- 判定：片側 $t$ の $p < 0.05$、かつ、同じ反応日の中で `chrono_risk` を 1,000 回入れ替える置換（乱数の種 0）の片側 $p < 0.05$ なら「支持」。
- 主に ChronoGPT を選んだ理由：2015 年までの文章しか知らず先読みがない。2020 年以降の全期間で使える。S1 の主なモデルと同じベクトル。

## 6. 副次（判定には使わない）

1. 変動率（2020 年以降）：`chrono_mid_risk`、`dict_uncertainty`、`dict_negative`、`finbert_negative` の同じ回帰。4 つで Holm。
2. 変動率（gpt-4o-mini の期間、2024-01-01 以降で `gpt_flags` と `gpt_risk` がそろう発表）：`gpt_flags`、`gpt_risk`、`chrono_risk`。3 つで Holm。
3. 比較の表（`results/comparison.csv`）：2 つの期間 × 4 つの目的変数（主と副 3 つ）× 各点数の係数・$t$・決定係数の増分。
4. **予測の比較**（実用の評価）：`log_rv_2_60` を、四半期ごとに、その四半期の前に 60 日の窓が閉じた発表だけで学習した最小二乗で予測する（2020 年以降の各四半期）。基準のモデル（`log_rv_pre`、`log_rv_long`、欠けの印、`log_float`、`abs_r_0_1`、`abs_sue`、`abs_rev`、欠けの印）と、それに `chrono_risk` を足したモデルの、標本外の二乗誤差を比べる。報告：標本外の決定係数（評価する標本の平均を基準）、二乗誤差の比、損失の差の平均の $t$（反応日ごとにまとめる）。
5. 頑健性：2021 年以降だけの主な検定。`abs_r_0_1` を統制から外した主な検定。

## 7. 限界

- 生き残った会社だけ（S1 と同じ）。上場をやめた会社は、変動率が高い時期に消えやすいので、高い変動率の発表が欠けている可能性がある。
- 変動率の持続は強く、過去の変動率だけで多くが説明できる。点数の増分は小さいと予想される。
- 日中のデータはないので、日次の終値だけで変動率を測る。
- gpt-4o-mini の期間は短く、`gpt_risk` は 60 日の窓が閉じるまで学習できないので、さらに短くなる。
