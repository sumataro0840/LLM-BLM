## 4. 探索（事前登録していない。結果を見た後に行った）

- **修正 4（真ん中の層）は、規則で試されていれば 3 つの切り方すべてで残っていた**。開発の期間で、ChronoGPT の増分は 0.49 → 0.80 ポイント（B、差の t 2.07）、A は t 2.57、C は t 2.86。一方、最後のトークンは悪化（t −1.4〜−2.0）、修正 5（圧縮）ははっきり悪化した（t −2.8〜−4.3）。FinBERT の修正 2（先頭＋末尾、全文）と修正 5 は、どれも良くならなかった。
- **事前登録したロジスティック回帰は、外れ値に弱い作りだった**。アナリスト予想との差（−500% などの極端な値を含む）を標準化したため、ふつうの値が押しつぶされ、全体の AUC（0.593）が、アナリスト予想との差 1 つだけの AUC（0.612）より低かった。そのため、文章の点数を足すと AUC がむしろ下がった。変数を学習期間の中での順位に直すと、土台の AUC は 0.611 になり、ChronoGPT を足すと +0.0026（95% 区間 +0.0005〜+0.0047）上がった。

## 5. 読み方

1. **読ませ方の小技は、ほとんど効かなかった。**表の切れ端や定型文を除いても、反応の説明力はほぼ変わらない。大事な記述は、もともと先頭にあった（見通しの語の最初の位置の中央値は約 1,200 字目）。
2. **効いたのは、埋め込みの取り方（真ん中の層）だった。**ただし規則の順番のせいで本番の判定には入っておらず、探索の結果にとどまる。最終の期間はすでに見たので、確かめるなら新しい事前登録で、まだ使っていない評価のしかたが要る。
3. **先読みのない ChronoGPT は、NLP を超える情報を持つ。**5 年以上の最終の期間で、支持の判定が 3 通りの切り方すべてで出た。ただし、反応で学習した BERT（追加学習）と gpt-4o-mini には及ばない。
4. **セクター単位の BLM では、どのモデルも効かなかった。**実験 7〜9 と同じく、決算の情報は月次の見通しにはほとんど残らない。
