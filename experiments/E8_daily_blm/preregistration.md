# E8 事前登録：発表日の終値で、LLM の情報はまだ株価に残っているか（日次の BLM）

状態：**確定**（2026-10-18）。この文書と `run.py` を同じコミットで固定してから、`run.py` を 1 回だけ実行する。実行に使ったコミットは `results/summary.json` に記録される。
この文書に書いていない分析は、すべて「探索」として別に報告する。

## 1. 位置づけ

- 実験 2〜4 の主な窓は、day 0 と day 1 の 2 取引日（day −1 の終値から day 1 の終値まで）だった。LLM の点数は、この 2 日の反応を強く説明した。
- 実験 2 の S1（day 2〜21 のドリフト）は +10bp で、有意でなかった。
- **day 1 だけ（day 0 の終値から day 1 の終値まで）は、まだ一度も見ていない。**
- 株価が day 0 の寄り付きで跳ねるので、日次のデータで取引できるのは、早くても day 0 の終値からである。day 1 の分に LLM の情報が残っていれば、その終値で取引する日次の戦略で拾える。
- 問い：**day 0 の終値の時点で、LLM の点数は、day 0 の反応そのものを超えて、翌日の超過リターンを予測するか。**

## 2. この文書を書いた時点で見たもの・見ていないもの

- **見たもの**：実験 2〜5 と X01〜X04 の結果。乱数を LLM の点数の代わりに入れて、回帰と日次の戦略のコードが最後まで動くこと（標本の大きさ 5,374 本、1 か月分の日ごとの見通しの数と、解けたかだけを確かめた。係数とリターンは見ていない）。
- **見ていないもの**：day 1 の超過リターンと LLM の点数の関係、日次の戦略のリターン。

## 3. 第 1 部：イベントの回帰（判定に使う）

- **標本**：実験 3 の標本 A（5,374 本、2023-11〜2026-08）。
- **目的変数**：`abn_r_1_1` = day 0 の終値から day 1 の終値までの、業種の ETF に対する超過リターン（実験 2 と同じ規則。上下 1% で丸める）。
- **注目の変数**：LLM の合成点数（標準化）。
- **統制**：実験 3 のモデル M1（実験 2 の統制＋アナリスト予想との差）に、**day 0 の超過リターン**（`abn_r_0_0`、上下 1% で丸めて標準化）を加える。day 0 の終値で分かっている情報なので、LLM はそれを超える必要がある。業種と四半期の固定効果。
- **主な検定 P**：注目の変数の係数。標準誤差は反応の日ごとにまとめ、同じ反応の日の中での置換 1,000 回（乱数の種 0）も行う。片側 t 検定で p < 0.05、かつ置換で片側 p < 0.05 なら「支持」。
- **副次（Holm で 2 つを補正）**：
  - S1：目的変数を day 1〜5 の超過リターン（`abn_drift_1_5`）にする。
  - S2：day 0 の反応を統制から除く（`abn_r_1_1`）。

## 4. 第 2 部：日次の BLM（判定には使わない。報告する）

- **期間**：2023-10 末から 2026-08 末までの取引日。過去に点数のある発表が 500 本たまった日から始める。
- **基準の比率**：前の月末の時価総額の比率を、その後の値動きで動かしたもの（その日の終値の時点）。
- **共分散**：前の月末の、直近 252 取引日の Ledoit–Wolf。
- **見通し**：その日が day 0 の発表がある銘柄だけ。点数は、それより前の日の全発表の平均と標準偏差で標準化する（その日以降は使わない）。q_i = Π_i + IC × σ_i × z_i（IC = 0.05）、Ω = τ diag(PΣP')、τ = 0.025、δ = 2.5。見通しのない日は基準の比率のまま。
- **最適化**：事前の TE 3%（年率）の上限つきの BLM の最適化。その日の終値で比率を決め、翌日の終値まで持つ（見通しは 1 日で消える）。
- **取引費用**：売買した額の 0.1%（片道）。月の最初の取引は、基準の比率からの差で数える（月ごとに並列で計算するため）。
- **報告するもの**：日次の超過リターン（費用の前と後）の平均と Newey–West（ラグ 5）の t、年率の情報比、実現の TE、回転率。点数を混ぜた対照（同じ日の銘柄の間で並べ替え、乱数の種 0）との差。

## 5. 限界

- 日次のデータなので、day 0 の寄り付きから終値までの動き（反応の大部分）は取れない。この実験が見るのは、その後に残った分だけである。
- 終値で売買できるとし、売買の影響（マーケットインパクト）は 0.1% の費用に含めた。
- 期間は約 2 年 9 か月で、標本 A は実験 2〜5 で一度見た期間である（day 1 だけの反応は見ていない）。
