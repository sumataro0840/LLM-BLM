# E8 の判定：発表日の終値の時点で、LLM の情報はもう株価に残っていない（支持されない）

- **実行**：2026-10-18。事前登録（`../preregistration.md`）と `run.py` をコミット `55ef830` で固定してから、1 回だけ実行した。数値は `summary.json`、日ごとの値は `by_day.csv`。

## 第 1 部：イベントの回帰（判定）

標本 A の 5,374 本。目的変数は day 0 の終値から day 1 の終値までの超過リターン。統制は実験 3 の M1 と day 0 の超過リターン。

| | 係数（1 標準偏差あたり） | t | p（片側） |
|---|---|---|---|
| **P：LLM の点数 → day 1** | **+3.6bp**（95% 区間 −4.0〜+11.3） | 0.93 | 0.18（置換 0.15） |
| S1：LLM の点数 → day 1〜5 | +11.4bp（−3.3〜+26.2） | 1.52 | 0.065（Holm 0.13） |
| S2：day 0 の統制なしで day 1 | +3.4bp | 0.87 | 0.19（Holm 0.19） |

**判定：支持されない。**

- 実験 2 の 2 日間の反応は、1 標準偏差あたり約 +100bp だった。day 1 に残るのは、多く見ても +11bp（95% 区間の上限）で、反応のほとんどは day 0 のうちに出る。
- day 0 の反応そのものも、day 1 を予測しなかった（−1.4bp、t −0.3）。翌日の続きも戻りもない。
- day 1〜5 は +11bp（t 1.5）で、有意ではない。実験 2 の day 2〜21（+10bp）と同じくらいの、小さく不確かな残りである。

## 第 2 部：日次の BLM（報告。判定には使わない）

2024-04-18〜2026-08-28 の 593 取引日。過去に点数のある発表が 500 本たまった日から始めた。見通しのある日は 467 日。

| | LLM の BLM | 点数を混ぜた対照 |
|---|---|---|
| 超過リターン（費用の前、年率） | +1.3% | +2.0% |
| 超過リターン（費用の後、年率） | **−20.0%** | −19.7% |
| 日次の回転率（片道） | 42% | 43% |
| 実現の TE | 3.4% | 3.2% |

- **費用の前でも、LLM は対照を上回らない**（差は −0.3bp／日、t −0.3）。第 1 部と合う。
- **費用で大きく負ける。**毎日、BLM の最適化をやり直すと、見通しのない銘柄も含めて比率全体が組み替わり、1 日に 42% が入れ替わった。片道 0.1% でも年 −20% になる。日次で BLM を使うなら、売買を抑える仕組み（回転率の罰則、見通しのある銘柄だけを動かす）が欠かせない。これは設計上の発見として記録する。
- 最適化の 32 日は「解の精度が低いかもしれない」（optimal_inaccurate）だった。費用の前の差が対照とほぼ同じなので、結論は変わらない。

## 読み方

1. 日次のデータで取引できる最初の時点（発表日の終値）では、LLM が読み取った情報はもう株価に入っている。実験 2〜4 の「2 日で織り込まれる」は、実際には「発表日のうちに」だった。
2. LLM の決算の読み取りで利益を出すには、発表直後（場中や時間外）に売買する必要がある。日次のデータでは検証できない。
3. 日次の BLM は、売買の多さで費用に負ける。月次の BLM（実験 7）では回転率は月 25% で、この問題は小さい。

## 限界

- day 0 の寄り付きから終値までの動き（反応の大部分）は、日次のデータでは取れない。
- 標本 A は、実験 2〜5 で一度見た期間である（day 1 だけの反応は見ていなかった）。
- 日次の戦略は、月ごとに並列で計算したため、月の最初の取引は基準の比率からの差で数えた。
