# G：小型株の BLM が効くことの確かめ（G1・G2・G5 の手順）

作成：2026-10-26。`やること.md` の G、総合報告書 3 の第 12 章の計画の 1 段目。

## 位置づけ

- **探索**である。元と新しい標本の BLM の結果（誤りを除いて年約 +3%）は、R1 の探索ですでに見ている。それでも、偽物の作り方・回帰の形・判定の線を、この文書とコードをコミットしてから 1 回だけ計算する。結果を見て手順を変えた場合は、変えたことを書いて別に報告する。
- 判定の線は「次の G3（事前登録の再検定）の設計を決めるための目安」で、ここで「証明」とは言わない。証明は G3 の事前登録した検定で行う。

## 共通の設定（R1 の探索の主なしきい値と同じ）

- 標本：元の 1,000 社（`data/smallcap.sqlite`）と新しい 1,000 社（`data/smallcap_rep.sqlite`）。それぞれ別に計算する。
- ポートフォリオ：S4 の主な形。2015 年末から四半期ごと、`chrono_ridge` の見通し、株価で補正した共分散（B）、TE の上限の校正あり（B_cal）。評価は 2017-01-01 以降。
- 株価の誤り：日々のリターンが +300% 超か −80% 未満なら欠け（S4 と同じく 0% 扱い）。R1 の探索の主なしきい値。
- 超過リターン：BLM − 範囲の中の標本の会社の浮動株時価総額加重。
- **費用**：この計画を書くときに、S4・R1 の検定に使った日々の超過リターン（`u`、R-BLM の年 +5.3%・誤りを除いた +2.9% など）は**費用の前**だったことに気付いた（費用は資産の推移だけに掛かっていた）。ここでは、組み直しの日の売買の量を BLM と帯の両方について記録し、片道 c の費用の後の超過リターンを「費用の前 − c ×（BLM の売買の量 − 帯の売買の量）」（組み直しの次の日に引く）で計算する。
- **しきい値なしとの照合**：費用の前・誤りを除いた本物の年の超過リターンは、R1 の探索の値（元 +3.04%、新 +2.86%）と一致するはず。

## G1：偽のビューとの比較

- 偽物：各組み直しの日に、ビューのある銘柄の z（点数の順位の正規点数）を、その日のビューのある銘柄の間で並べ替える（`numpy.random.default_rng(seed).permutation`、seed = 0〜99 の 100 回、組み直しの日ごとに同じ乱数の列から順に引く）。どの銘柄にビューがあるか、共分散、Ω、TE の校正（偽物自身の過去の偏りで行う）、費用は本物と同じ。
- 統計量：2017 年以降の年の超過リターン（日次の平均 × 252）。主は**片道 0.3% の費用の後**（偽物も同じ費用）。費用の前も並べる。
- 報告：本物の値、偽物 100 回の平均・5%・50%・95% 点、本物以上の偽物の数、p = (1 + 本物以上の数) / 101、本物 − 偽物の平均（＝点数の中身の分）。情報レシオ・実現の TE も並べる。
- 目安：両方の標本で p < 0.05。

## G2：ファクターでの説明

- 被説明変数：本物の日々の超過リターン（片道 0.3% の費用の後）。あわせて「本物 − 偽物 100 回の平均」の日々の差も。
- 説明変数：Fama–French の 5 因子（Mkt-RF、SMB、HML、RMW、CMA）とモメンタム（Mom）、日次。`data/blm_2015.sqlite` の `factor_returns`（2026-08-31 まで）。重なる日だけを使う。
- 推定：最小二乗、Newey–West の標準誤差（ラグ 21）。α は切片 × 252（年率）。
- 報告：α（年率）、t、片側 p、各因子の係数と t、決定係数。因子なしの平均との比較。
- 目安：両方の標本で本物の α の片側 p < 0.05。

## G5（前半）：費用

- 本物の B_cal の超過リターンを、片道 0%（費用の前）・0.3%・0.5%・1.0% で出す。年の超過リターンと R1 の検定（63 日の循環ブロック・ブートストラップ 2,000 回）。
- 組み直しごとの売買の量（Σ|Δw|）の平均も出す。容量（売買代金に対する割合、市場への影響）は後半として別に行う。

## 実行

    python experiments/G_proof/run.py orig real              # 本物（売買の量も記録）
    python experiments/G_proof/run.py orig shuffle 0 14      # 偽物 seed 0〜13（並列に分けて走らせる）
    ...（rep も同じ）
    python experiments/G_proof/analyze.py                     # G1・G2・G5 の集計 → results/summary.json

日々の系列は `results/<sample>/`（本物 `real.csv`、偽物 `shuffle_<a>_<b>.csv`）。

## G3 の検出力（2026-10-26 に追加、G1 の偽物の計算中・その結果を見る前）

- G3 の標本は残りの 400 社しかない。使い終わった 2 つの標本から 400 社を無作為に抜き出し（seed 1000 + k、k = 0〜9、各標本 10 回）、本物と同じ BLM（比べる相手も同じ 400 社）で計算する（`power.py`）。
- 片道 0.3% の費用の後の R1 の検定（63 日の循環ブロック・ブートストラップ 2,000 回）で片側 p < 0.05 になる割合を、検出力の見積もりとする。G3 のデータは使わない。

## 寄与と G6（2026-10-27 に追加。G1・G2・G5 の結果を見た後の探索）

- **寄与**（`contrib.py`）：本物の BLM の日々の差（費用の前）を、銘柄ごとに（BLM の比率 − 相手の比率）× その日のリターンに分けて、2017 年以降で足す。報告：上位 10・20 銘柄の合計が差の何割か、上位 10・20 銘柄を除いた差（年）、年ごとの差、量子コンピュータの会社（IONQ・QBTS・QUBT）の寄与。照合：銘柄の合計が run.py の本物の差と一致すること。
- **G6**（同じ計算の中）：BLM と同じ日程・銘柄・誤りの除き方で、ビューのある銘柄のうち点数の上位 20% を、浮動株時価総額で加重したもの（S1 の月次の対決と同じ加重）と等金額のもの。比べる相手は BLM と同じ。費用の前と片道 0.3% の後の年の差、R1 の検定、実現の TE。S1 の月次の対決（2020 年以降、毎月、誤りを除かない）との違いを切り分ける。
