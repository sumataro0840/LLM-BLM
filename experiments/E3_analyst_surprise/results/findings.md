# E3 の判定：アナリスト予想との差を統制しても、LLM の点数は反応を説明する（支持）

- **実行**：2026-10-18。事前登録（`../preregistration.md`）と評価のコードをコミット `1f39810` で固定してから、1 回だけ実行した。数値は `summary.json`。
- **データ**：アナリスト予想は Alpha Vantage の EARNINGS（発表前のコンセンサス EPS と実績 EPS）。利用規約が個人の非商用で再許諾できないので、予想の値そのものは Git に入れていない（DB と `data/cache/alphavantage/` にある）。
- **標本**：E2 の標本 A と同じ（2023-11〜2026-08、5,374 本）。そのうち 5,200 本（96.8%）に予想があった（上回り 4,086、一致 229、下回り 894）。E2 で一度反応を計算した期間の再利用である。

## 主な検定

| | LLM の合成点数の係数（1 標準偏差あたり） | t | 置換 |
|---|---|---|---|
| M0：E2 と同じモデル | +120bp | 9.41 | — |
| **M1：予想との差を統制** | **+116bp**（95% 区間 +92〜+141） | 9.37 | 片側 p = 0.001 |

**判定：支持。**予想との差を加えても、LLM の係数は 97% が残った。M1 で、予想との差そのものは +69bp（t 6.2）、前年同期との差（SUE）は +8bp（t 1.1）だった。

R1 では、上回りの印が +266bp（t 6.9）だった。R4 では、驚きの裾が長すぎて予想との差の係数が消える（t 0.8）が、LLM の係数は変わらない。

## 読み方

1. **LLM の点数は、アナリスト予想との差とはほぼ別の情報を持つ。**LLM は予想との差を少しは読んでいる（S3）が、それを統制しても係数はほとんど縮まない。総合報告書 2 で最大の限界とした「本当の驚きを文章から読んでいるだけではないか」は、少なくとも EPS の予想については当たらない。
2. **予想との差の中でも、LLM の点数は効く**（探索の図）。予想を上回った発表の中で、点数の 5 分位ごとの反応は −0.54%、+0.34%、+0.20%、+0.81%、+1.56%。下回った発表の中では −4.31%、−1.72%、−1.74%、−1.68%、−1.28%。下回ったうえに点数が最も低い発表（ガイダンスの引き下げなど）で、とくに大きく下げる。
3. **取引できる価値は、やはりない**（S2）。予想との差を統制しても、発表の後のドリフトは有意でない。

## 限界

- 予想は EPS だけで、**売上の予想とガイダンスの予想（会社の見通しと市場の期待の差）は統制していない**。LLM の効果の一部は、これらを文章から読んでいる可能性が残る。
- 予想との差は「÷ |予想|」で測ったので、予想が 0 に近い発表で値が極端になる（丸めで対処、R2・R4 で確認）。株価で割る測り方は、EPS と株価の株式分割の扱いが揃わないので使わなかった。
- 予想のデータの元（どの会社の集計か）は公開されていない。
- 標本 A は E2 で一度見た期間である。
