# E3 事前登録：アナリスト予想との差を統制しても、LLM の点数は発表への反応を説明するか

状態：**確定**（2026-10-18）。この文書と評価のコード（`run.py`）を同じコミットで固定してから、`run.py` を 1 回だけ実行する。実行に使ったコミットは `results/summary.json` に記録される。
この文書に書いていない分析は、すべて「探索」として別に報告する。

## 1. 位置づけ

- 実験 2（E2）で、gpt-4o-mini の合成点数は、発表をはさむ 2 取引日の超過リターンを強く説明した（1 標準偏差あたり +120bp、t 9.41）。
- ただし、数値の驚きは「前年同期との差（SUE）」でしか統制していなかった。LLM が本文の「予想を上回った」といった記述から、本当の驚きを読んでいるだけかもしれない（総合報告書 2 の最大の限界）。
- この実験では、アナリスト予想（Alpha Vantage の EARNINGS、発表前のコンセンサス EPS と実績 EPS）との差を統制に加える。
- **標本 A は、E2 で発表への反応を一度計算した期間である。**この実験は、新しい統制を加えた新しい検定として事前登録するが、同じ標本の再利用であることを報告で明記する。

## 2. この文書を書いた時点で見たもの・見ていないもの

- **見たもの**
  - E2 の結果（`experiments/E2_event_reaction/results/`）
  - アナリスト予想と発表の照合の件数（標本 A の 96.8% に予想あり）
  - 驚き（%）の分布（1% 点 −62.7%、中央値 +4.6%、99% 点 +175%）、上回り・一致・下回りの数（4,086・229・894）
  - LLM の点数・SUE・驚きの順位相関（LLM と驚き 0.16、SUE と驚き 0.19）
- **見ていないもの**：アナリスト予想との差と、株価の反応との関係。この実験の回帰はどれも計算していない。

## 3. データ

- **標本**：E2 の標本 A（5,374 本）と同じ。`experiments/E2_event_reaction/results/panel.csv` を使う（E2 の `run.py` で DB から作り直せる）。
- **アナリスト予想との照合**：発表の受理日（ニューヨーク時間）に最も近い報告日を持つ、同じ銘柄の四半期を、前後 3 日以内で選ぶ（`events/estimates.py` の `match_releases`）。
- **予想との差**：`surprise_pct`（＝（実績 EPS − 予想 EPS）÷ |予想 EPS| × 100、データの元が計算した値）。

## 4. 変数

E2 の主な検定のモデル（目的変数、LLM の合成点数、統制、固定効果、丸め、標準化、欠けの扱い）をそのまま使い、次を足す。

- `analyst_surprise`：`surprise_pct` を標本 A の全体で上下 1% で丸め、標準化する。
- `analyst_missing`：予想と照合できなかった発表を 1 にする印（その発表の `analyst_surprise` は 0）。

## 5. 主な検定と判定

- **モデル M1（主）**：E2 の主なモデルに `analyst_surprise` と `analyst_missing` を加える。
- **標準誤差**：反応の日ごとにまとめる（CR1）。
- **置換の対照**：同じ反応の日の中で LLM の合成点数を入れ替えて 1,000 回（乱数の種 0）。
- **判定**
  - 「支持」：M1 の LLM の合成点数の係数が、片側 t 検定で p < 0.05、かつ置換で片側 p < 0.05。
  - 「支持されない」：それ以外。
- **あわせて報告する**
  - M0（E2 と同じモデル、同じ標本）の LLM の係数と、M1 の係数の比（統制を足してどれだけ縮んだか）
  - M1 のアナリスト予想との差の係数
  - 決定係数の増分

## 6. 副次の分析（Holm で 3 つを補正）

- **S1**：M1 のアナリスト予想との差の係数は正か（データの確かさの確認）。
- **S2**：目的変数を 2〜21 日目のドリフトに変えた M1 で、LLM の合成点数の係数は正か。
- **S3**：LLM は驚きを読んでいるか。目的変数を `analyst_surprise` にし、LLM の合成点数と E2 の統制（目的変数に関わる `abn_pre` も含む）と固定効果で回帰した、LLM の係数は正か。

## 7. 頑健性（判定には使わない）

- **R1**：連続の驚きの代わりに、「上回り」「下回り」の 0／1 の印（一致が基準）を入れる。
- **R2**：目的変数・LLM の点数・驚きなどを、反応の日の四半期ごとの順位（0〜1）に直す。
- **R3**：予想と照合できなかった発表と、受理が場中でデータ上は引け後の発表（反応の日が 1 日ずれるおそれ）を除く。
- **R4**：驚きを丸めない。
