# E9 の判定：先読みのない ChronoGPT の見通しで約 10 年回した月次の BLM は、時価総額とほぼ同じ（支持されない）

- **実行**：2026-10-19。事前登録（`../preregistration.md`）と `run.py` をコミット `0856fd0` で固定してから、1 回だけ実行した（主な実行）。数値は `summary.json`、月ごとの値は `by_month.csv`。
- **事前登録からのずれ（実装の誤り）**：事前登録では判断日を 2016-03〜2026-07（125 か月）としたが、主な実行は **2017-01〜2026-07 の 115 か月**だった。判断日の一覧を X02 の関数から借りたが、その関数は 2017-01 からしか日付を返さなかった。結果を見る前の計画の変更ではなく、コードの誤りである。
- **日付を直した実行**：日付の部分だけを直し（コミット `2eadaa3`）、事前登録どおりの 125 か月で 1 回だけ実行した。結果は `corrected_dates/`。結論は同じ。判定は、事前登録どおり主な実行で行う。

## 主な検定

| | 主な実行（115 か月） | 日付を直した実行（125 か月） |
|---|---|---|
| 費用の後の月次の超過リターン（対 時価総額） | **+0.003%** | +0.002% |
| Newey–West の t（片側 p） | 0.04（0.49） | 0.02（0.49） |
| 費用の前 | +0.06%／月 | +0.06%／月 |
| 情報比（年率、費用の後） | 0.01 | 0.01 |
| 累積（BLM ／ 時価総額） | +303.9% ／ +304.8% | +354.0% ／ +356.3% |
| 時価総額を上回った月 | 50% | 49% |
| 回転率（月、片道） | 30% | 30% |

**判定：支持されない。**約 10 年で、費用の後の超過リターンはほぼ 0 だった。費用の前の +0.06%／月（年 約 +0.7%）を、取引費用がちょうど打ち消している。

## 副次の分析（判定には使わない）

| | 主な実行 | 日付を直した実行 |
|---|---|---|
| S1 点数を入れ替えた対照との差（費用の前、月） | +0.15%（t 1.78） | +0.14%（t 1.75） |
| 　対照の超過リターン（費用の後、月） | −0.24% | −0.23% |
| S2 見通しがすべて版 2015 の月 | 81 か月、+0.007%（t 0.08） | 91 か月、+0.005%（t 0.05） |
| S3 2023-10 以降の月 | 34 か月、−0.007%（t −0.04） | （同じ） |
| S4 実現の TE（目標 3%） | 3.04% | 3.04% |

- **S1**：本物の予測は、入れ替えた対照より月 +0.15% 良い。ただし t 1.8 で、5% では有意でない。実験 7（31 か月、t 2.3）と同じ向きで、大きさも近い。比率を動かすこと自体の損（対照の −0.24%）を、予測の中身がほぼ埋め合わせて、市場並みに戻している、という形である。
- **S4**：この戦略自身の過去で校正した TE の上限（平均 2.77%）で、実現の TE は 3.04% と、約束の 3% にほぼ一致した。

## 読み方

1. **決算の読み取りを月次の BLM に入れても、約 10 年で市場を上回らない。**実験 8 のとおり、情報は発表日のうちに株価に入るので、月末にはほとんど残っていない。
2. **予測の中身はゼロではない。**ランダムに比率を傾けるより良く、その差は約 10 年で月 +0.15%（t 1.8）。ただ、費用を払うほどの大きさではない。
3. **実験 7 の「やや上回る」（+0.10%／月）は、31 か月の偶然の範囲だった**可能性が高い。見通しの源が違う（実験 7 は gpt-4o-mini）ので厳密な比較ではないが、同じ期間（2023-10 以降、S3）でも今回はほぼ 0 だった。
4. TE の校正は、2016 年からの約 10 年でも働いた。

## 限界

- 見通しの予測は、gpt-4o-mini の半分以下の強さ（実験 5）。
- DB の構成銘柄は 2015〜2019 年に少ない（指数との差は年 0.26%）。
- IC 0.05 は仮の値で、選び直していない。

## 追記（2026-10-19）：α の単位

見通しの α に日次の σ を使い、1 か月の保有に合わせた √21 の調整をしていなかった（期間に合った大きさの 4.6 倍）。補足実験 X05（`experiments/X05_alpha_scale/`、探索）で α の倍率を 0.001〜2 に変えて計算し直した。倍率 0.03 以上では TE の上限が毎月効き、ポートフォリオはまったく同じだった（期間に合った倍率 0.22 も含む）。この結論は α の単位の誤りに影響されない。
