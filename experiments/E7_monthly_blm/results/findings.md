# E7 の判定：結果を全部入れた月次の BLM は、時価総額を有意には上回らない（支持されない）

- **実行**：2026-10-18。事前登録（`../preregistration.md`）と `run.py` をコミット `55ef830` で固定してから、1 回だけ実行した。数値は `summary.json`、月ごとの値は `by_month.csv`。
- **期間**：判断日は 2024-01〜2026-07 の各月末、31 か月。
- **規模**：銘柄は平均 491、見通しのある銘柄は平均 454（最初の月だけ 145）。
- **最適化**：31 か月すべて解けた。

## 主な検定

| | 値 |
|---|---|
| 費用の後の月次の超過リターン（対 時価総額） | **+0.10%**（年 約 +1.2%） |
| Newey–West の t | 1.22（片側 p 0.12） |
| 費用の前 | +0.15%／月 |
| 情報比（年率、費用の後） | 0.55 |
| 累積（31 か月） | BLM +68.5%、時価総額 +63.8% |
| 時価総額を上回った月 | 55% |
| 回転率（月、片道） | 25% |

**判定：支持されない。**向きはプラスだが、31 か月では有意でない。事前登録の 6 章のとおり、この期間で検出できるのは年率の情報比が 2 を超える場合だけで、0.55 は「ない」とも「ある」とも言えない大きさである。

## 副次の分析（判定には使わない）

- **S1 点数を混ぜた対照との比較**：本物の LLM の BLM は、点数を銘柄の間で並べ替えた BLM（20 通りの平均）を、費用の前で月 +0.20% 上回った（NW の t 2.30）。並べ替えた対照は、費用の後で月 −0.17% と、時価総額に負けた。
  - BLM の比率を動かすこと自体（費用と、見通しの分布）は損をする。それを上回る分が LLM の点数の中身にあった、と読める。
  - ただし 31 か月で、判定に使わない分析である。実験 2 で月次のドリフトが有意でなかったこととも合わせ、「月次でも弱い情報が残っているかもしれない」という仮説の段階にとどめる。
- **S2 TE**：事前の上限は X03 の校正で平均 1.95% になり、実現の TE は平均 2.46% と、約束の 3% 以内に収まった。X03 の校正は、LLM の見通しでも働いた。

## 読み方

1. 「LLM の決算の読み取り＋正しい Ω＋Ledoit–Wolf＋校正つきの TE」の BLM は、動く。約束の TE を守りながら、市場並みかやや上の成績だった。
2. 決算の情報の大部分は 2 日で織り込まれる（実験 2〜4）ので、月次の BLM の上乗せは、あっても小さい。今回の +1.2%／年は有意でない。
3. 並べ替えた対照に勝ったことは、次に長い期間で確かめる価値がある。先読みのない ChronoGPT（実験 5）で 2016 年からの点数が作れれば、同じ BLM を約 10 年で検定できる。

## 限界

- 31 か月しかない。
- IC 0.05 は仮の値で、選び直していない。
- 時価総額の比率は浮動株で調整していない。上場をやめた銘柄は、その後 0% とした。
