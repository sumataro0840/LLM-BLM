# 設計書の最初の版へのレビュー：gpt-5.5 と gemini-3.1-pro-preview の回答（2026-10-16）

===== openai =====
1. **事前登録として成立しにくい**
   - 評価期間が 2026-08 までで、設計書の日付は 2026-10-16。さらに既存資料で主要な結果を読んだ後に H02〜H04 を設計している。
   - H02〜H04 は「事前登録実験」ではなく「既知結果に基づく再分析」と明記するか、別の未評価期間・未使用データを主評価にする必要がある。

2. **判断日終値での売買が先読みになる可能性**
   - LLM 入力に判断月の日次リターン、つまり判断日当日の終値を含めるなら、その同じ終値で買うのは実行不能。
   - 「判断日終値までの情報で、翌営業日の始値または終値で売買」に直すか、「判断日前営業日までの情報で判断日終値売買」に統一する必要がある。

3. **銘柄ユニバースの先読み・生存者バイアスが残っている**
   - 「判断日に S&P500 に在籍」とあるが、Wikipedia・yfinance ベースだと時点別構成銘柄、上場廃止、買収、ティッカー変更を正しく再現できない恐れがある。
   - H07 の「在籍が続いた銘柄から 100 銘柄」は明確に未来情報を使う選別。判断日時点で選べる銘柄だけにする必要がある。

4. **時価総額・財務指標の時点管理が不十分**
   - yfinance の shares outstanding、EDGAR/XBRL、`stock_metrics` が「判断日時点で利用可能だった値」か不明。後日修正値・将来提出値・現在の株式数を使うとリークする。
   - 各特徴量に「公表日・取得可能日」を持たせ、判断日以前に利用可能な値だけで学習・最適化する条件を明記すべき。

5. **「t<2 なら仮説支持」は検定設計として誤り**
   - H02、H04、H07 などで「有意でない＝効果なし／情報なし」と判定している。これは帰無仮説を支持したことにならない。
   - 「効果なし」を主張するなら、事前に最小有意味効果量を決めて同等性検定・非劣性検定にするか、「検出されなかった」に表現を限定する必要がある。

6. **主検定と多重比較の定義が曖昧**
   - Holm 補正は「H02〜H07 の 6 つ」とあるが、H03 は複数条件の結合、H04 は実質 3 仮説、H05 は相関閾値＋IC、H06 は全銘柄・35日以内など複数の判定がある。
   - 各仮説につき、補正対象となる単一の p 値、片側/両側、符号、失敗時の判定を明確に固定する必要がある。

7. **較正係数 `b_t` と Ω の実装が破綻しやすい**
   - 共通ルールで「3 か月までは b=0」としている一方、H03/H04 で `τΣ(1/b_t-1)` を使うため、`b_t=0` で無限大・ゼロ除算になる。
   - `b_t≤0`、`b_t=0`、`b_t≥1`、標準誤差による縮小で `\hat b=0` の場合をどう扱うかを事前に定義する必要がある。

8. **H03 の順位ビューは単位と比較対象が混ざっている**
   - `α_i = IC_t σ_i z_i` の `σ_i` は「月次」と書かれているが、BL の `Π`、`Σ`、`q` は日次単位。日次・月次の変換が必要。
   - さらに「`μBL=Π+α`」としており、BL の `q,P,Ω` を通さないため、絶対ビュー・相対ビューとの比較で「ビュー形状」と「BL を迂回した効果」が混ざる。日次単位に直し、同じ BL 枠内で比較する設計に修正すべき。

===== gemini =====
実験計画書をレビューした結果、実験前に修正すべき重要な問題を8点指摘します。

1. **H02の検定設計の誤り（多重共線性）**
   LLMの予想と判断月の入力（リターン等）をFama-MacBeth回帰で同時に説明変数にすると、両者の強い相関（0.89）による多重共線性でLLM側の標準誤差が膨張し、$t$値が不当に下がります。これにより「予測力なし」と誤判定しやすくなるため、入力を回帰した残差（直交化）を使って検定するべきです。

2. **H04の置換検定（パーミュテーション）の回数不足**
   置換による対照群が50通りでは、95パーセンタイル（上から2.5番目）の推定が極めて不安定です。正確な経験的$p$値を算出するため、最低でも99通り（できれば499〜999通り）の計算が必要です。

3. **H06の実装上の落とし穴（HTMLタグと文字数制限）**
   EDGARのEX-99.1（決算発表文）の先頭約15,000文字を直接渡すと、HTMLタグや定型の免責事項（ボイラープレート）だけで文字数を消費し、肝心の業績見通し部分が切断される可能性が高いです。入力前にタグ除去などのクリーニング処理が必須です。

4. **過剰な多重比較補正**
   H02〜H07はそれぞれ全く異なる独立した仮説・指標（回帰係数、IC、リターン等）を検証しています。これを一つにまとめてHolm法で補正すると、ただでさえ30ヶ月で低い検出力（検定力）をさらに下げてしまいます。仮説のファミリーを分割するか、主要な検定ごとの単独評価とするべきです。

5. **H03の対照条件の交絡（順位ビュー）**
   順位ビューの期待リターンの式（$\alpha_i = \IC_t \cdot \sigma_i \cdot z_i$）にボラティリティ（$\sigma_i$）が掛けられています。これでは絶対ビューや相対ビューとの成績差が、「順位変換」によるものか「ボラティリティによるスケーリング」によるものか区別できなくなります。

6. **H05の判定基準の根拠不足**
   「相関の絶対値が0.3未満」というカットオフ基準に統計的な裏付けがありません。わずか30サンプルの点推定値で区切るのではなく、相関が有意でないことの検定や、信頼区間の上限を用いた基準に変更すべきです。

7. **H03におけるタイ（同値）の順位処理の欠落**
   LLMが出力する期待リターン（丸められた数値）には多数の同値（タイ）が発生する可能性が高いです。順位の正規化（$\Phi^{-1}$）を計算する際、同順位に対して平均順位を割り当てるなどのタイ処理を明記・実装しないと、順位付けが歪みます。

8. **財務指標のデータリーク（先読み）への対策不足**
   H02やH06の対照群で用いる「売上と利益の前年比」などのファンダメンタル指標について、判断日（月末）時点での**公表遅延（パブリケーション・ラグ）**が考慮されているか言及がありません。決算期末ではなく、実際の発表日ベースで利用可能だったデータのみを使う制約を明記する必要があります。
